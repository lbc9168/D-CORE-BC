# 一带一路可再生能源数据库 (BRI_RE_Database) — 项目知识库

## 项目目标
追踪并记录中国企业参与的海外可再生能源电站项目信息，重点覆盖"一带一路"沿线国家和地区。
为政策研究、学术分析和行业报告提供结构化的基础数据支撑。

## 数据范围

### 主要收录类型（以发电为目的的电站）
- 光伏 (Solar PV)
- 风电 (Wind)
- 水电 (Hydro)
- 核电 (Nuclear)
- 地热及余热 (Geothermal / Waste Heat)
- 生物质 (Biomass)
- 储能 (Energy Storage / BESS)
- 综合能源 (Integrated / Hybrid，如光伏+储能)

### 次要收录类型（有中国企业参与则收录，但分析时单独处理）
- 火电 (Thermal)：燃气/煤电等化石能源电站，若有中国企业参与仍需记录
- 新能源制造业 (Manufacturing)：海外组件厂、电池厂、风机制造厂
- 输变电建设 (Transmission)：输电线路、变电站等电网基础设施

### 排除范围
- 仅处于投标/招标阶段（未确认中标或签约）的项目
- 仅获批但无中方参与确认的项目
- 国内（中国境内）项目

### 地理范围
- 一带一路沿线国家为主
- 全球范围内有中国企业参与的均可纳入

### 时间范围
- 2013年至今（一带一路倡议提出以来）

## 中国参与企业——字段填写规范

> 母子公司完整层级对照表在每次运行时已自动注入 prompt（来源：supporting_docs/company_hierarchy.json）。
> 本节提供字段填写逻辑和特殊场景指引，不重复列举具体子公司。

### implementing_entity 与 subsidiary_name 的区分规则

| 字段 | 填写内容 | 示例 |
|---|---|---|
| `implementing_entity` | **出现在新闻中最高层级的中国母公司**，优先使用集团简称 | 中国电建、国家电投、三峡集团 |
| `subsidiary_name` | **实际执行项目的子公司**（若新闻有明确提及） | 中国水电三局、上海电力、三峡能源 |

**判断步骤：**
1. 新闻中出现的中国企业名称，先对照注入的层级表查找归属
2. 找到归属 → 填顶层集团名为 `implementing_entity`，填新闻中实际提到的子公司名为 `subsidiary_name`
3. 未在层级表中找到 → 如实填写新闻中出现的企业名，`subsidiary_name` 留空
4. 新闻中只提到母公司，没有子公司信息 → `subsidiary_name` 留空，不推测

### is_central_soe 填写规则（三级优先级）
1. 企业出现在运行时注入的层级表中 → 使用表中 `is_central_soe` 字段值（true/false）
2. 未在层级表中，但企业名（母公司）出现在 supporting_docs/soe.md 官方央企名录中 → true
3. 以上均无匹配 → false（默认非央企）
- **注意**：`is_central_soe` 始终基于 `implementing_entity`（母公司）判断，不基于子公司名称

### 特殊场景
- **金融机构**：中方金融机构（国家开发银行、中国进出口银行、中国银行、中国建设银行、
  中国工商银行、中国农业银行、中国出口信用保险公司/Sinosure 等）不填入 `implementing_entity`，
  记录于融资字段；`involvement_type` 填"融资方"
- **联合体**：多家中国企业联合投标/实施时，`implementing_entity` 填主要牵头方，其余可在
  `subsidiary_name` 中用分号分隔列出
- **设备供应商**（民营为主，通常不在层级表中，`is_central_soe = false`）：
  - 组件：隆基绿能(LONGi)、晶科能源(Jinko)、晶澳科技(JA Solar)、天合光能(Trina)、通威股份(Tongwei)
  - 逆变器/储能：阳光电源(Sungrow)、比亚迪(BYD)、宁德时代(CATL)、亿纬锂能(EVE)
  - 风机：金风科技(Goldwind)、远景能源(Envision)
  - 工程机械：三一重工(Sany)、徐工集团(XCMG)

## 数据质量标准
- 仅收录已明确中标、签约、开工、在建或竣工的项目
- 项目名称统一格式：「国家 + 区域 + 装机容量(MW) + 项目类型 + "项目" + 补充信息」
- 装机容量：混合能源项目填写所有子项之和，单位统一为 MW
- 无法确定的字段留空，不得填写推测内容
