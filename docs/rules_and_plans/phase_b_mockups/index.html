一、三版方案怎么看

三版的唯一差异轴是「多域切换」的信息架构；子类筛选、储能/金额详情增强、域3 精简列表等共通设计（见第三节）三版完全一致。每个文件顶部有交互提示，可点击切换三个域实际感受。

二、数据基础（决定设计的硬事实）

  • 域构成（过基线 policy 后可见数）：域1 新能源发电 1,512（现状口径不变，含 ES，487 GW 与 Q2 季报一致）；域2 储能·光储 307 = ES 178 + 综合能源·光储 129；域3 输变电·制造业 598 = TX 437 + MF 161。
  • 域2 度量覆盖率：storage_energy_mwh 215/307 = 70%（合计 160.4 GWh）、storage_power_mw 105/307 = 34% → MWh 默认着色成立；光储项目 pv_capacity_mw 覆盖 141/175 = 81%。
  • 域3 只能按项目数着色：TX transmission_capacity_mw 覆盖仅 2.7%、line_length_km 20.6%、voltage_kv 是等级不可求和；MF 产能单位异质（GW/年 27 / 万吨/年 20 / GWh/年 14）。
  • 金额字段现状 0/3541 全空（仅 2026-07 起新数据有值）→ 已拍板条件渲染。
  • 子类分布：光伏 995 = 集中式 912（含 NULL 默认）+ 分布式 83；综合能源 480 = 光储 175 + 其他 305（NULL 默认）。
  • 光储 ≠ 储能：光储是混合电站（capacity_mw 计 MW，进域1 GW 聚合）；域2 是"视图"非"分区"——光储项目在域1 按 MW 看、在域2 按 MWh 看，两域聚合口径独立、无重复计数。capacityPolicy（ES/TX/MF 不进 GW）语义不动。
