① 度量选择器收进域卡片："用什么口径测量"是域的属性，不是筛选条件。FilterBar 的 Color By 下拉被移除（净减一控件）。域1 度量：Project Count（默认）/ Capacity (MW)。
② 项目数角标：1,512 / 307 / 598 为真库实数。取舍：Grid & Mfg 的 598 需要预取 tx/mf_flat（各 431KB/142KB，很小）——建议首屏 idle 时预取仅为算角标，或未加载前角标显示"—"（实现阶段二选一）。
③ 子类二级筛选：与其他版本一致——Project Type 选中光伏/综合能源时 Subtype 药丸出现，取消时联动清空。
④ 视角条高度控制：卡片单行紧凑（py≈6px，整条约 48px），比筛选栏略高一点点；1366×768 下地图仍有约 440px 高。若嫌占高，可做"折叠态只显当前域"变体（次选）。
⑤ 域2 度量三选：Storage Capacity (MWh) 默认（覆盖率 70%）/ Storage Power (MW)（34%）/ Count。图例单位随度量自动切换（colorScale 泛化 unit 参数）。
⑥ 域2 筛选栏收窄：Project Type 不渲染（域内构成固定）；Status/SOE/Region/BRI/年份保留（对 Project 型数据仍有效）。
⑦ 域3 度量退化为单项：只显示 Project Count 一个胶囊（不可切换）——TX 输送容量覆盖 2.7%、MF 单位异质，是数据硬约束不是设计偷懒。
⑧ 域3 筛选栏：TX/MF 子域 Tab 顶替 Project Type 的位置；Status 筛选隐藏（无时间线数据）；BRI/Dev.Status 靠前端 ISO3 静态表派生（tx/mf_flat 无这两个字段）。

V3 评估（推荐）

✓ 优点：域与筛选彻底分层（视角条浅色底 vs 筛选栏白底），不会被误读为筛选条件；度量选择器随域收纳，天然杜绝"储能域看到 MW 图例"这类口径错位；保持 Map 单页统一体验；顺带简化了筛选栏。
✗ 风险：Map 页顶部从 1 行变 2 行，挤压地图高度约 48px（小屏需验证）；角标数字需预取 tx/mf 数据（体积小，可接受）。
工作量：M（与 V1 同量级：共通基建一样，多一个 DomainSwitcher 组件、省一个 Color By 下拉适配）。
