① FilterBar 与 V3 完全一致：Color By 下拉移除（度量选择器在域卡片里）、Subtype 条件出现；不新增任何布局行，筛选栏回到单行。
② 实现方式（可行性确认）：MapPage 地图容器已是 position:relative，省级返回按钮 / 图例 / 「无省级信息」按钮全部是同款 overlay 浮层——DomainSwitcher 与 V3 是同一个组件，只是挂载到地图容器内（absolute top-3 left-3 z-20 + bg-white/92 backdrop-blur），工作量与 V3 相同。
③ 好处：地图保持满高（比 V3 多出约 48px 可视高度）；域切换控件与它控制的地图在同一视觉空间，"切的是地图视角"的隐喻更直接。
④ 遮挡评估：卡片浮层盖住地图左上角一条。世界图左上多为北冰洋/格陵兰高纬区域，实际遮挡少；但省级视图下返回按钮也在左上角（现有 top-3 left-3）——实现时省级视图下视角条整体下移一行、或收起为紧凑态（图标+数字），返回按钮保持原位。这是 V3b 相对 V3 唯一多出的适配点。
⑤ 窄屏行为：卡片组 flex-wrap 换行会多盖一行地图；窄屏（<1100px）建议自动降级为"图标+数字"紧凑卡片（去掉英文名副标题），实现阶段处理。
⑥ 与 V3 的取舍总结：V3b 省 48px 地图高度、隐喻更贴地图；V3 的视角条永远不遮地图内容、省级视图零适配。两者组件级代码 95% 相同，后期互换成本低。

V3b 评估（V3 的地图浮层变体）

✓ 优点：地图满高（不损失 48px）；不新增布局行，页面结构与现状完全一致；域控件贴着地图，"切视角"隐喻最直接；复用现有 overlay 模式，实现无新风险。
✗ 代价：浮层盖住地图左上一条（世界图影响小，省级视图需下移/收起适配）；地图截图/导出时卡片会入镜。
工作量：M（与 V3 完全同级，多一个省级视图适配点）。
