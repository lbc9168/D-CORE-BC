## 已实现功能

### CrossVerificationTool（外部信源交叉验证）

四阶段流程：

**1. GDELT 批量查询**
按国家×能源类型从 GDELT 国际新闻数据库拉取标题（本地缓存，零 token 消耗）。

**2. 多语言向量匹配**
Gemini text-embedding-004 嵌入，余弦相似度筛候选对（阈值可配置，默认 0.65）。

**3. LLM 确认**
逐对判断文章是否报道该项目（high/medium/low 置信度）。

**4. 写回数据库 + 导出清单**
低置信度记录输出 Excel 人工核查清单。
