## 已实现功能

### 新闻爬虫
`tools/news_crawler_tool.py`（crewai 工具）

- **数据源**：goalfore.cn 项目新闻页
- **支持**：自定义日期范围、关键词过滤、起始页码（`start_page`）
- **输出**：`data/raw/Energy_News_Raw_*.xlsx`
- **原始新闻备案**：所有抓取新闻同时写入 `data/raw_news.db`（URL 唯一去重，跨批次持久化）

**爬虫安全机制：**
- `_request_with_retry()`：指数退避重试，最多 4 次（3s→6s→12s→24s + jitter）
- 列表页失败跳过本页继续，连续失败 ≥ 5 次才终止（原为直接 break）
- sleep 改为随机区间 1.0–3.0s（原固定 1s），降低反爬检测风险
- 单次请求超时从 10s 放宽至 20s
- **断点续爬**：每页完成后写入 `raw_news.db` 的 `crawler_checkpoints` 表（`batch_id` + `last_page`），中断后通过 `start_page` 参数从断点恢复

### AI 提取筛选
`tools/project_extractor_tool.py`（crewai 工具）

- **模型**：Gemini gemini-2.5-flash-lite（google.genai SDK）
- 包含完整的 9 条筛选规则（剔除非电站、制造业、招标阶段等）
- 中文项目名强制约束（防止 LLM 输出英文）
- **双语支持**：LLM 同时输出 `Project Name (EN)`、`Implementing Chinese Entity (EN)` 等英文字段
- **输出改为 SQLite**（原 Excel 三文件已废弃）：
  - `data/projects.db` — 有效项目（`extracted_projects` 表，含 `imported_to_s02a` 增量标志）
  - `data/review.db` — 无中方参与（`no_chinese_records`）+ 被过滤文章（`discarded_records`）
  - `data/All_AI_Results_*.json` — AI 原始结果（存放在 projects.db 同级目录）
- **重试机制**：AI 调用失败时最多重试 3 次（指数退避 2s/4s），全部失败才记入 `discarded_records`
- **增量去重**：每次运行前从 `projects.db` + `review.db` 预加载已处理 URL，跳过重复项，防止重复入库
- **发布日期前向填充**：URL 日期无法解析时自动沿用上一条有效发布日期
- **金融机构处理**：中方金融机构统一写入 `chinese_entities`，`involvement_type = 融资方`（不再有独立 `chinese_banks` 字段）

## 批量并发采集

用于历史数据补录，在 `s01_data_collector_filter` 中新增：

```bash
cd s01_data_collector_filter
uv run run_parallel          # 使用默认参数（2023-01-01 → 2026-03-08，按月拆分）
```

或在代码中调用：
```python
from s01_data_collector_filter.main import run_parallel, split_date_range

run_parallel("2024-01-01", "2025-12-31", chunk_months=1)   # 24批并发
run_parallel("2023-01-01", "2026-03-08", chunk_months=3)   # ~13批（限速时推荐）
```

## 大规模历史补录（两阶段：顺序爬虫 → 并发 AI 提取）

适用于超长时间段（如 2018–2026）回补，避免直接全并发触发目标站或 LLM 限流：

```bash
cd s01_data_collector_filter
uv run run_bulk
```

或在代码中调用：
```python
from s01_data_collector_filter.main import run_bulk

run_bulk("2018-01-01", "2026-03-08")  # 默认：按月爬取、批间延迟10s、AI提取4并发
run_bulk("2024-01-01", "2025-12-31", max_extract_workers=8)
run_bulk("2018-01-01", "2026-03-08", chunk_months=3, crawl_delay=15.0)
```

- **Phase 1（顺序爬虫）**：按时间段倒序抓取，批次间 `crawl_delay` 等待，支持 `start_page` 页码接力
- **Phase 2（并发提取）**：直接从 `raw_news.db` 读取新闻并并发调用 LLM 提取，无需依赖中间 Excel

## 数据接口

- **输入**：goalfore.cn 新闻页（网络请求）
- **输出**：
  - `data/raw_news.db` — 原始新闻备案（crawler_checkpoints 表用于断点续爬）
  - `data/projects.db` — 有效提取项目（`extracted_projects` 表）
  - `data/review.db` — 无中方参与 + 被过滤记录
