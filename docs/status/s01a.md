# 阶段一A：新闻爬虫（s01a_news_crawler）

> 最后更新：2026-06-24

**子项目路径：** `s01a_news_crawler/`

---

## 职责

按日期范围 + 关键词从 goalfore.cn 抓取项目新闻，去重写入 `raw_news.db`，作为 s01b AI 提取的原料库。

---

## 当前功能

### NewsCrawlerTool（`tools/news_crawler_tool.py`）

纯 Python 爬虫类（无 LLM、无 crewAI）：

- **数据源**：goalfore.cn 项目新闻列表页（`https://news.goalfore.cn/topstories/project`）。
- **关键词过滤**：正文含任一关键词（能源/电力/电站/MW/GW/风电/水电/光伏/储能…）才标记 `passed_keyword_filter=1`。
- **反爬与稳健性**：User-Agent 轮换；指数退避重试（最多 4 次，3s→6s→12s→24s + jitter）；翻页/详情页随机间隔 1–3s；列表页连续失败 ≥5 次才终止。
- **断点续爬**：每页完成后写 `crawler_checkpoints` 表（`batch_id` + `last_page`），中断后由 `start_page` 从断点恢复。
- **连续重复早停**：写库后检测命中已入库 URL，连续 ≥5 条则停止（常量 `CONSECUTIVE_DUP_MAX=5`），避免重复爬已处理区段。

### 入口（`main.py`）

| 入口 | 用途 |
|------|------|
| `run()` / `run_single(start, end, …)` | 单批爬取（直调 tool，参数精确透传；供 pipeline 调用） |
| `run_bulk_crawl(start, end, chunk_months, crawl_delay)` | 大规模历史补录：按月拆分、**倒序**逐批爬取、批次间延迟、页码接力 |
| `split_date_range(start, end, chunk_months)` | 将日期范围拆成按月的多组调用参数（被 bulk 复用） |

---

## 如何运行

```bash
cd s01a_news_crawler
uv sync                  # 首次安装
uv run s01a_news_crawler # 单批爬取（= main.run()）
uv run run_bulk_crawl    # 历史补录（默认 2018-01 → 2026-03，按月，批间 10s）
```

---

## 输入 / 输出

- **输入**：goalfore.cn 新闻页（联网请求）。
- **输出**：`data/raw_news.db`，两张表：
  - `raw_news`：`url`(UNIQUE)、`title`、`content`、`author`、`publish_date`、`crawl_time`、`passed_keyword_filter`、`batch_id`。URL 唯一去重、跨批次持久化。
  - `crawler_checkpoints`：`batch_id`(PK)、`last_page`、`updated_at`，断点续爬用。
- Excel 输出默认关闭（`save_excel=False`）；数据一律以 `raw_news.db` 为准。

---

## 关键依赖与约束

- 依赖：requests、beautifulsoup4、pandas、pydantic（爬虫本身不调用 LLM）。
- 入参（`source_url` / `start_date` / `end_date` / `keywords`）经 Pydantic `NewsCrawlerInput` 校验。
- 是阶段一的第一步，输出的 `raw_news.db` 即 s01b 的默认输入。
