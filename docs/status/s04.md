# 阶段四：网页可视化（s04_web_visualization）

> 最后更新：2026-08-22（网页全量审计纠错数据双站发布）

**子项目路径：** `s04_web_visualization/`

---

## 职责

React 单页前端，可视化主库数据。**纯前端、零后端**，直接 fetch s03 导出的静态 JSON/CSV。部署在两处：公司服务器（<https://d-core.iigf.com.cn>，主站）+ GitHub Pages（镜像）。

品牌名：**D-CORE: Database of Chinese Overseas Renewable Energy Projects**。界面为纯英文。

---

## 技术栈

- React 18 + TypeScript + Vite + Tailwind CSS（自定义品牌色/类别色，无重型 UI 库）。
- 地图：react-simple-maps + world-atlas TopoJSON；图表：recharts。
- 枚举来自根 `enums_mapping.json`，构建期经 `scripts/copy-enums.mjs` 拷入 `src/generated/enums.json`（`predev`/`prebuild` 自动执行）。
- 前端枚举加载器同时暴露 `generation_source`、`storage_status`、`technology_tag.allowed_categories` 以及 TX/MF 的 `data_domain/spec_profile`；页面布局和既有 TX/MF 展示字段不变。

## 数据流

```
s03 run_export → public/data/{projects_flat,stats_country,stats_entity,stats_timeline}.json
                              + tx_flat.json / mf_flat.json（Map 页"输变电·制造业"域懒加载消费）

s04 前端直接 fetch 静态文件（纯前端；tx/mf_flat 由 DataContext.ensureTxMfLoaded 按需 fetch）
```

## 已实现功能

1. **视角条（Map/Table/Overview 共用，Phase B2）**：页顶浅品牌色条，**两张互斥数据集卡片**（Power Generation 与 Grid & Manufacturing，图标+英文名+中文副名+项目数角标，互斥可相加）。域状态持久化在 URL query（`?domain=txmf`；旧 `?domain=storage` 兼容映射为发电域+MWh 透镜），切域清空类别/子类/状态/子域筛选、保留年份/地区/BRI/LDC/SOE：
   - **新能源发电（renewable，默认）**：现状全量口径（PV/WD/HY/GT/BM/HB+ES 可见）；Map 页度量选择器 3 项：项目数/装机 MW/**储能容量 MWh**（储能功率 MW 不作地图度量，仅详情展示）。
   - **储能透镜（非独立域）**：选中储能度量时，地图按 MWh/MW 着色、列表聚焦 `isStorageLens` 子集（储能类别 ∪ 光储子类 ∪ 任何披露储能字段的项目——数据驱动并集，地图值 ⊆ 列表；储能数据补全后自动扩大），列表标题切换为 Storage-related Projects。
   - **输变电·制造业（txmf）**：消费 `tx_flat/mf_flat.json`（懒加载 + `enrichTxMf` 派生 kind/BRI/LDC/dev_status/has_soe，基线同主表：剔中港澳台 + `event_year<2022`）；度量仅项目数（TX 输送容量覆盖 2.7%、MF 单位异质的数据硬约束）；筛选栏换 All/Transmission/Manufacturing 子域 Tab、隐藏 Status（专表无时间线）。
2. **世界热力图**：`country_iso` 匹配，按当前度量着色（`MetricKey` 泛化：count/capacity_mw/storage_power_mw/storage_energy_mwh；三档离散图例 + "No data" 项；图例标题/单位随度量自动切换）。
3. **省级热力图**：按需加载 `/geo/provinces/{ISO3}.geojson`，点击省份过滤；聚合同样走 `metricValue()`（两域+透镜通用）；含与世界图同款图例（分箱按省级数据重算，标题/单位随当前度量；位置抬高一行以避开右下"无省级信息"按钮）。2026-08-15 已从稳定工作区的已审导出库恢复 worktree 省份映射：主表 `2262/3541`、TX `247/440`、MF `99/162` 有 province；主表有省份项目与 Natural Earth feature 的直接归一化匹配率为 `2191/2262=96.9%`，省级色块恢复。
4. **项目列表**：主表 `ProjectList` 按 `display_order` 降序显示新项目优先（含子类描边 badge；storage 透镜变体 MWh 优先规模标签；ES 项目 capacity 空时回退储能双指标）；专表 `TxMfProjectList` 按 `event_year` 降序、同年按 `project_id` 升序（TX 电压/里程/输送、MF 产能值+单位）。
5. **项目详情 Drawer**：右滑覆盖层，接受 `Project | TxMfProject` union 按 kind 分支渲染：
   - 主表 `ProjectDetail`：关键数字条含 装机/光伏子项/储能功率/储能容量（有值才出现对应格）；标签行与基本信息含子类（Subtype）；融资区块四字段条件渲染（`contract_amount_usd`/`financing_amount_usd` 有值才显示行，区块出现条件覆盖四字段）；External Links 与信息来源目前均不在网页展示，底层导出字段保留。
   - 专表 `TxMfProjectDetail`：精简版（关键规格/基本信息/实体），无时间线/融资/开发商区块（字段不存在≠空态）；实体卡片与主表共用 `EntityList`。
6. **筛选栏**：年份双柄范围滑块、Region 二级、BRI、LDC、SOE 两域通用；能源类型多选 + **子类二级筛选**（选中光伏/综合能源时出现「Subtype」，选项带类别前缀消歧，类别取消时联动清空）仅发电域；Status 四大类仅发电域。
7. **Overview 仪表盘**：接入视角条（隐藏度量胶囊）按域两套统计——发电侧：`YearPills` + **5 KPI**（活跃/装机 GW/**储能相关项目·ΣGWh**/国家/中企）+ `StatusDonut` + `TopCountriesBar`×2 + `TimelineChart` + `EntityChart`；产业链侧（全 count 口径，年份=终态事件年）：4 KPI（TX/MF/国家/**参与中企数**，不放总数）+ 三张图**各带独立 TX/MF 图表级筛选**（`KindToggle`，互不影响）——状态 donut（latest_stage 派生，`StatusDonut` 的 `mix`+`headerExtra` prop）+ Top 国家（项目数）+ 企业排名（`TxMfEntityChart`，视觉与发电侧 `EntityChart` 同款品牌渐变横条）+ 专属口径说明条；**趋势图产业链侧不展示**（终态快照无区间语义）。统计纯函数在 `utils/overviewStats.ts` + `utils/txmfOverviewStats.ts`。
8. **数据表格**：接入视角条（隐藏度量胶囊）按域两套列组——发电表 10 列（ID/名称/国家/省/类型/装机容量/阶段/年份/开发商/央企；储能 MW/MWh 仅在项目详情展示）；产业链表 10 列（ID/名称/国家/省/类型/**Specs 合并列**/阶段/年份/第一实体/央企）。搜索/排序/分页按域各自工作；CSV 下载恒为全量单文件（39 列含 TX/MF）+ 数据字典下载。

### 筛选语义（4 大类时间模型）

- 年份范围 `[start, end]`；主表项目存在性 = `stage_events` 区间与所选范围交叠；**txmf 专表退化为单点包含**（只有终态 `event_year`）。
- 状态按 4 大类 `viz_group`（pre_construction/under_construction/completed/acquired），取**范围结束年**当时状态；拟开发/Unknown 不展示。大类英文标签（enums 单一可信源）：Pre-construction / **In Construction** / **Construction Completed** / Acquired。
- 基线策略：排除 CHN/HKG/MAC/TWN、最后事件年 < 2022（`BASELINE_YEAR=2022`）、隐藏类别（核电/火电/制造业/输变电——制造业/输变电现经专表进 txmf 域展示，主表流仍排除）、unknown 主体、无容量的容量类别；txmf 专表同构基线（中港澳台 + `event_year<2022`）。
- capacityPolicy 语义不变：ES/TX/MF 不进装机 GW 聚合（`metricValue("capacity_mw")` 内保留 `hasCapacity()` 守卫；Overview 486.97 GW 与改版前一致）。

## 如何运行

```bash
# 1. 生成数据（自动同步到 s04/public/data/）
cd s03_data_exporter && uv run run_export

# 2. 首次：下载省级地图（需 pip install pyshp）
cd s04_web_visualization && python scripts/download_geo.py

# 3. 启动开发服务器
npm install && npm run dev
```

### 构建与本地部署

```bash
cd s04_web_visualization
npm run build          # 输出 dist/（base="./"，HashRouter 适配 GitHub Pages 子路径）
```

默认“前端部署”只做到本地 `dist/` 构建和完整性自检，不自动发布任何线上环境。公司主站与 GitHub Pages 属于独立线上发布步骤，须用户明确指定目标并批准；完整门禁见 `s04_web_visualization/DEPLOY.md`。

- 本地预览：`cd dist && python -m http.server 8080`（必须经 HTTP，不能直接双击 index.html）。
- 线上部署（两处，均见子项目 `DEPLOY.md`）：
  - 公司服务器（主站）：<https://d-core.iigf.com.cn>，SSH 上传 `dist/` 整份替换 `/home/app/ydyl/dist/`（先备份 `dist_bak`）。
  - GitHub Pages（镜像）：手动 `git push` 把 `dist/` 推到 `gh-pages` 分支。
