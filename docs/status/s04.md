## 技术栈

- React 18 + TypeScript + Vite
- Tailwind CSS（自定义品牌色/类别色）
- react-simple-maps（地图）+ recharts（图表）
- 无重型 UI 库，纯 Tailwind 实现组件
- 纯英文界面（已移除中英文切换，语言固定为英文）

---

## 数据流

```
s03_data_exporter（uv run run_export）
  → data/output/projects_flat.json
  → data/output/stats_country.json
  → data/output/stats_entity.json
  → data/output/stats_timeline.json
        ↓ 自动同步到 s04_web_visualization/public/data/
s04 前端直接 fetch 静态 JSON（纯前端，零后端）
```

> s03 main.py 写入 JSON 时自动同步到 `s04/public/data/`，无需手动复制。

## 已实现功能

1. **世界热力图**：country_iso 匹配，支持按项目数/装机容量着色，对数色阶
2. **省级热力图**：按需加载 `/geo/provinces/{ISO3}.geojson`，点击省份过滤项目
3. **无省级信息按钮**：单独列出省份字段为空的项目
4. **项目列表**：国家/省份级别项目列表，含能源类型标签/阶段标签/容量（全英文）
5. **项目详情**：实体列表、时间线，央企标注 Central SOE badge
6. **筛选栏**：年份滑块、多选（类型/阶段/企业）、BRI 筛选、LDC 筛选、**央企筛选（SOE filter）**、着色方式切换
7. **图表面板**（世界视图）：堆叠柱状图（年份趋势）+ 水平柱状图（企业排名）
8. **数据表格**：全量数据，支持搜索、多列排序、分页（50条/页）、CSV 导出（含 Central SOE 列）
9. **全英文界面**：所有字段值、标签均显示英文（category_en / latest_stage_en / involvement_type_en / financing_model_en）

## 省级地图数据准备

```bash
cd s04_web_visualization
pip install pyshp            # 首次：安装 shapefile 解析依赖
python scripts/download_geo.py    # 下载 Natural Earth 10m admin1，按国家拆分
```

- **数据源**：Natural Earth 10m admin1（NACI CDN / Amazon S3，zip 约 10-15 MB）
- **注意**：50m 版本仅含 9 个大国，必须用 10m 版才有全球完整覆盖（~4500+ feature）
- **输出**：`public/geo/provinces/{ISO3}.geojson`（~242 个国家）
- **国内访问**：两个官方源在国内均有访问限制，需 VPN

## 启动方式

```bash
# 1. 生成 JSON 数据（会自动同步到 s04/public/data/）
cd s03_data_exporter && uv run run_export

# 2. 下载省级地图（首次，需 pip install pyshp）
cd s04_web_visualization && python scripts/download_geo.py

# 3. 启动开发服务器
npm install && npm run dev
```

## 构建发布（本地离线运行）

```bash
cd s04_web_visualization
npm run build    # 输出到 dist/（已配置 base="./" 支持相对路径）

# 启动本地服务（无需 Node.js，Python 即可）
cd dist && python -m http.server 8080
# 访问 http://localhost:8080
```

> 注意：dist/ 必须通过 HTTP 服务器访问，不可直接双击 index.html（fetch 请求受浏览器 CORS 限制）

## 2026-04-15 白屏修复

- **路由结构修正**：`App.tsx` 改为标准 React Router v6 嵌套路由（`path="/"` 父路由 + `index` 子路由 + 相对路径子路由），消除无路径父路由的边缘情况
- **高度链修正**：`Layout.tsx` 的 `<main>` 补充 `flex flex-col`；`MapPage` / `TablePage` 根 div 从 `h-full` 改为 `flex-1`；stub 页面同步移除冗余 `h-full`
- **ProvinceMap zoom 上限**：`computeCountryFit()` zoom 上限从 50 改为 6，防止小国/岛国产生极端缩放值导致 d3-zoom SVG 坐标溢出崩溃（白屏）
- **ProvinceMap idle 状态**：loading 判断新增 `"idle"` 状态，避免首次挂载时短暂显示"无省级数据"占位符
- **构建 base 修正**：`vite.config.ts` 的 `base` 改为 `./`（相对路径），避免生产静态部署到非 `/BRI_RE_Database_v2/` 子路径时，点击国家后请求 `geo/provinces/*.geojson` 指向错误地址引发白屏
- **GeoJSON 结构校验**：`useProvinceGeo.ts` 新增 `FeatureCollection` 校验，若返回体不是标准省级 GeoJSON（如 404/代理返回错误 JSON），统一降级为 `unavailable`，避免地图渲染阶段抛异常
- **ProvinceMap 防崩增强**：`ProvinceMap.tsx` 对 `onMoveEnd` 坐标与 zoom、fit 计算结果做有限值校验；`computeCountryFit` 增加异常兜底并在异常时回退默认视图，降低特定国家几何数据导致的渲染崩溃风险
- **局部错误边界**：`MapPage.tsx` 为省级地图增加 `ProvinceMapErrorBoundary`，若仅省级地图渲染失败，页面其余区域保持可用，不再整页白屏
- **省级地图渲染链路简化**：`ProvinceMap.tsx` 移除 `ZoomableGroup` 动态平移缩放，改为受控 `projectionConfig`（center/scale）渲染并加 feature 过滤与 finite 校验，规避部分浏览器在复杂几何下的 SVG 变换异常
- **根因修复（CD[o] is not a function）**：`ProvinceMap.tsx` 向 `Geographies` 传参从 `FeatureCollection` 对象改为 `features` 数组；兼容 `react-simple-maps@1.x` 对 object 输入按 TopoJSON 解析的行为，修复省级地图加载后渲染崩溃
- **投影兼容修复（最终）**：`ProvinceMap.tsx` 的投影从 `geoEquirectangular` 改为 `geoMercator`；`react-simple-maps@1.x` 不支持 `geoEquirectangular` 字符串投影，导致省级地图在 loading 后进入渲染阶段触发 `CD[o] is not a function`
- **地图缩放交互恢复**：`WorldMap.tsx` 与 `ProvinceMap.tsx` 均启用 `ZoomableGroup` 受控 `center/zoom`，支持滚轮缩放与拖拽平移

- **地图背景色更新**：`MapPage.tsx`、`WorldMap.tsx`、`ProvinceMap.tsx` 的背景色统一改为 `#d9ddd9`
