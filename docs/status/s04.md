# 阶段四：网页可视化（s04_web_visualization）

> 最后更新：2026-06-24

**子项目路径：** `s04_web_visualization/`

---

## 职责

React 单页前端，可视化主库数据。**纯前端、零后端**，直接 fetch s03 导出的静态 JSON/CSV。已部署到 GitHub Pages。

品牌名：**D-CORE: Database of Chinese Overseas Renewable Energy Investment**。界面为纯英文。

---

## 技术栈

- React 18 + TypeScript + Vite + Tailwind CSS（自定义品牌色/类别色，无重型 UI 库）。
- 地图：react-simple-maps + world-atlas TopoJSON；图表：recharts。
- 枚举来自根 `enums_mapping.json`，构建期经 `scripts/copy-enums.mjs` 拷入 `src/generated/enums.json`（`predev`/`prebuild` 自动执行）。

---

## 数据流

```
s03 run_export → public/data/{projects_flat,stats_country,stats_entity,stats_timeline}.json
                              + events_export.csv + metadata.json
   （s03 写入时自动同步，无需手动复制）
        ↓
s04 前端直接 fetch 静态文件（纯前端）
```

## 已实现功能

1. **世界热力图**：`country_iso` 匹配，按项目数/装机容量着色（对数色阶，三档离散图例）。
2. **省级热力图**：按需加载 `/geo/provinces/{ISO3}.geojson`，点击省份过滤；另有"无省级信息"按钮列出省份为空的项目。
3. **项目列表**：国家/省级项目列表，含类别/状态标签与容量。
4. **项目详情 Drawer**：右滑覆盖层（遮罩/Esc 关闭），卡片化排版，央企 Central SOE 徽章。
5. **筛选栏**：年份**双柄范围滑块** `[start, end]`、多选（类型 / Status 四大类 / 企业）、BRI、LDC、央企（SOE）筛选、Region（5 大洲/20 小区）二级、着色方式切换。
6. **Overview 仪表盘**：`YearPills` 年份胶囊 + 4 张 KPI 卡 + `StatusDonut` 状态构成 + `TopCountriesBar`×2（项目数/装机）+ `TimelineChart`（里程碑趋势）+ `EntityChart`（企业排名）；统计纯函数在 `utils/overviewStats.ts`。
7. **数据表格**：搜索、多列排序、分页（50/页）、下载静态 `events_export.csv`（事件×公司实体级，26 列）。

### 筛选语义（4 大类时间模型）

- 年份范围 `[start, end]`；项目存在性 = 其 `stage_events` 区间与所选范围交叠。
- 状态按 4 大类 `viz_group`（pre_construction/under_construction/completed/acquired），取**范围结束年**当时状态；拟开发/Unknown 不展示。
- 基线策略：排除 CHN/HKG/MAC/TWN、最后事件年 < 2022（`BASELINE_YEAR=2022`）、隐藏类别（核电/火电/制造业/输变电）、unknown 主体、无容量的容量类别。

## 如何运行

```bash
# 1. 生成数据（自动同步到 s04/public/data/）
cd s03_data_exporter && uv run run_export

# 2. 首次：下载省级地图（需 pip install pyshp）
cd s04_web_visualization && python scripts/download_geo.py

# 3. 启动开发服务器
npm install && npm run dev
```

### 构建与部署

```bash
cd s04_web_visualization
npm run build          # 输出 dist/（base="./"，HashRouter 适配 GitHub Pages 子路径）
```

- 本地预览：`cd dist && python -m http.server 8080`（必须经 HTTP，不能直接双击 index.html）。
- 线上部署：GitHub Pages，手动 `git push` 把 `dist/` 推到 `gh-pages` 分支（流程见子项目 `DEPLOY.md`）。

---

## 输入 / 输出

- **输入**：`public/data/` 下静态 JSON/CSV（由 s03 生成同步）+ `public/geo/provinces/{ISO3}.geojson`（`download_geo.py` 生成）。
- **输出**：`dist/` 静态站点。

---

## 省级地图数据

```bash
cd s04_web_visualization
pip install pyshp
python scripts/download_geo.py    # Natural Earth 10m admin1，按国家拆分到 public/geo/provinces/
```

- 必须用 **10m** 版（50m 仅含 9 个大国）；输出约 242 个国家的 GeoJSON。
- ⚠️ 两个官方源在国内均有访问限制，需 VPN 或镜像。
