# s02e_source_finder 当前状态

## 职责与范围

参考链接发现、正文核验、数据库持久化及机会性发电容量补空，位于正常Pipeline的归一化之后、S03导出之前。默认Gemini 2.5 Flash-Lite + Google Search找源，DeepSeek摘录，GPT-6 Luna Low对未登记或归因待定的来源进行证据审核；确定性规则继续核验项目身份、动作、日期和量值。Luna来源审核不替换正文抽取模型。

- 私有找源范围为当前网页所有项目，以及仅因年份被隐藏的2018年以来项目；网页基线仍为2022年及以后。真实S03投影生成2654个参考项目/3332事件，其中2092当前公开、562仅年份隐藏。
- 缺容量池仅放宽发电容量条件，仍要求可再生发电、中方参与及其他发布规则；311项目/333事件。储能、制造业产能及Unknown分类不参与容量补全。
- 常态目标不排除试点已见项目，也不把特定参与句式作为参考池准入门槛。明确原文支持的日期才可形成事件卡，其余保守保留项目级参考。

## 常态运行与恢复

`recurring.run_incremental(main_db, raw_db, config_path=None)`由Pipeline默认调用；`run_source_finder=False`显式跳过。`supporting_docs/source_finder_config.json`绑定主库、新闻库、私有工作目录及机构登记表；调用账本持续计量，但当前授权不设费用、搜索次数或模型调用次数上限。非生产库不自动使用生产配置。

`data/recurring/queue.sqlite`按事件保存业务指纹、状态及尝试次数：新/变更目标进入队列，优先处理尝试次数少的目标，同等次数下新增/变更批次排在历史积压之前。已有当前事实匹配且有效的合格项目/事件参考即结束，不因其他候选失败重复处理。旧版已完成但无合格来源的任务也进入一次有界第二遍；`result_json`记录`bounded-source-search-v1`及`qualified`、`no_reference_found`或`retry_pending`。前两种结果终止本轮任务；上游事实变化或80天到期后按新generation重新核验。公开链接仍最多90天有效，不以缓存复制延长有效期。

每批最多25事件；正式配置当前为4路并发。首次尝试最多2轮搜索、合计4候选正文。第二遍仅处理无合格来源的事件：旧候选最多4页各重试一次，仍无合格结果则Gemini另搜最多4个新网页；再无结果则另搜最多4个，之后终止本轮找源。新搜索请求带策略版本和已尝试URL列表，不复用首遍搜索；跨轮排除同URL、HTTP/HTTPS、常见跟踪参数变体，以及重定向回旧文章的候选。Gemini不足4个新结果时按实际返回量处理，不追加第三轮。任一合格参考立即结束，成功按原事务和证据门禁入库；容量仅顺带检查同批正文。

第二遍进度存于`results/*-bounded-source-search-v1.progress.json`，保存旧候选游标、两轮新候选和已完成验证，重启不重复已走完的阶段。首次应用前自动保存队列备份及hash清单；原主库备份/写入验证继续生效。认证、余额、限流或预算暂停保留恢复位置，不算找源耗尽；成功调用缓存复用，中断且结果未知的请求不自动重发。批次`processed`仍表示本轮结束的队列项，另以`found_reference`、`exhausted`区分找到来源和本轮未找到来源。账本继续累计计量，不清零。

## 来源准入与动态登记

生产配置开启`source_review_enabled`。未登记域名/机构、原发布者未核实、平台原文要求等，交给`source_admission.py`中的GPT-6 Luna Low（`source-admission-v1`）核对当前页面的网站名、页眉页脚、来源声明与正文。可靠且引文可定位的页面当次继续项目/事件审核，无需等域名累计次数；证据不足保持待定。正文目标不发给来源审核，最多发送16000字符候选正文、4000字符身份信息及来源声明。请求、模型、effort、prompt/schema与响应按既有预算账本保存，源文本作为数据而非指令。

累计至少6个不同文章URL且Luna确认机构/媒体拥有该完整hostname、有可定位归属证据时，写入私有`data/recurring/source-admission.sqlite`的`admitted_hosts`。按URL去掉fragment、HTTP/HTTPS重复及常见跟踪参数，同一文章关联多Activity或多次重跑不加次数；重要文章query参数保留。次数不是可靠性证明。自动登记仅作用于完整hostname，不推断父域/兄弟子域；真实共享平台只逐文章/发布账号审核，不提升全域。旧名单将专业媒体笼统标作platform时，模型有机构运营证据可修正该完整host的运行时分类。

转载原名保留并绑定出处引文；同集团署名由模型证据判断，不因缺少旧登记记录直接拒绝。来源放行仍不绕过中文、项目/期次、事件和容量证据门禁。动态登记与页面审核最多80天有效，原手工名单和既有关系不覆写；同名机构保留原关系ID。

旧来源拦截优先重审，携带原候选URL并保持已付费搜索generation及成功抽取缓存。策略升级只迁移来源规则，旧成功任务不整体重跑；新策略结果使用独立版本后缀，缺少身份文本字段的旧页面缓存重新抓取。审核费用计入原`calls.sqlite`的`new_extract`，沿用同一账本记录，不新增独立钱包或重置费用。HTTP明确失败仍可在后续运行有界重试；中断未决或用量未知的输运错误保留全额预留，并阻止自动付费重发。

## 数据与输出

主库`external_reference_candidates`保存项目/事件绑定、参考元数据、正文hash、判断及必要引文。抓取全文、模型响应和调用账本留在私有目录。每批写前保留SQLite备份及hash清单，事务内重验冻结项目/事件/参与关系，检查ID、外键及非目标表不变性；旧成功参考独立保留，重新核验失败仅降级相应URL。

容量只补既有事件的空numeric和空raw；明确项目、期次、单位及已有事件绑定才能写入，不推算、不新建事件。冲突和已有raw值保留；通过项同步capacity_mw/raw/details/source及`capacity_review_audit`，授权类型明确为workflow_authorized，不冒称逐条人工审阅。S02A现有capacity_review_guard保护后续合并。

`data/recurring/external-references.json`为`external-references-v1`交接快照。S03显式快照优先；正常独立导出通过`external_references_config.json`优先读取已生成的常态快照，尚未生成时读取原有样本快照。英文容量证据不进入公开链接。主表/TX/MF共用既有参考组件；历史项目保存链接后仍按原年份规则隐藏。
