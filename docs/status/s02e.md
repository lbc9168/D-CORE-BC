# s02e_source_finder 当前状态

## 职责

为项目详情页提供正确、可用、确实属于该项目的 external links。合格链接逐条展示，错误或不确定候选逐条隐藏；不设覆盖率硬门槛。当前为开发验证，已接入s03可选JSON导出参数并通过隔离正常页面验证；本地正式JSON与dist已启用已有合格链接，线上站点及主流水线未启用本轮链接更新。

## 当前功能

- 只读主库项目、事件、参与方和原始新闻；有限抓取中文HTML/文本PDF，旧链接仅作为候选。
- 结构化抽取与确定性判定分开。保留可定位的项目证据、来源、量值、实际动作、阶段与日期检查；同项目但事件证据不足时降为项目参考，报道的附带段落也可作项目参考。旧抽取未识别该项目时保持隐藏，不凭关键词自动翻转。
- 搜索连接失败、网页失败和抽取格式失败局限单条；成功搜索引用继续消费。认证、余额、限流故障阻止新增相应供应商请求，已有结果继续处理。默认不重试，未知请求状态保持待确认。
- 每条候选记录 success/excluded/pending/failed 处理状态及独立原因；批次complete表示已选候选均有状态，不表示全部成功或达到来源覆盖率。来源未登记、署名未核实、格式失败与错误项目分别记录。
- 账本以完整无凭据请求参数识别跨运行搜索/抽取缓存；同目标及同正文的已有抽取可跨判定版本重用并重新校验。历史失败不自动重调，格式失败保留脱敏模型响应与已知用量。旧原始记录不覆盖。
- MF制造产能同时传value/unit，GW/年等年制造产能规范为MW/year，与装机MW隔离；保留模型原单位与原文量值证据。
- 主表及TX/MF详情共用external_references组件，缺失/不合格/过期参考隐藏，不回退旧链接。本地s03/s04正式JSON已提供该字段，production build正常表格页已验证显示/隐藏；线上站点未发布本轮链接。

## 如何运行

模块环境见[README](../../s02e_source_finder/README.md)。source_loop为最多5事件的开发入口，acceptance保留原命令名但接受1至10个不同项目及已有结果，标签manifest只保留出处，不要求正例数量。默认预览零外部调用；联网须显式--execute及已有预算授权。

本轮零API混合执行验证见`data/development-validation-v1/`，使用既有缓存和本地模拟，实际网络请求被测试拦截；正确候选在网页/格式/错误项目之后仍进入真实详情投影，重复执行无新增调用。

## s03元数据交接

`python -m s02e_source_finder.export_references --inputs <frozen-inputs.json> --reviewed <reviewed-rows.json> --output <private-snapshot.json>` 将已复核rows（event_id/decision/external_reference/reason）转为 `external-references-v1`。绑定冻结上下文和父文件hash，仅输出元数据；待确认/失败保留原因，原响应和标签不改，不发外部请求。s03通过可选 `--external-references` 消费该快照。实际隔离闭环证据位于 `data/export-development-validation-v1/`。

## 输入/输出

输入为只读源库、冻结上下文/目标卡/候选正文、机构记录及可选已有响应。输出为模块私有data下正文、JSON、日志、SQLite调用账本及候选结果；无源库写入或XLSX回填；本地正式JSON仅链接字段更新，修改前已备份，并核对其他字段及源库哈希。

## 关键依赖与约束

Python 3.11–3.13、requests、BeautifulSoup、pypdf、Pydantic、pandas及s03构建器；凭据仅来自本地环境。默认不自动重试失败请求，不扩样、不启动全量、不以覆盖率判断批次完成。

已有13条候选已用于诊断，只称开发验证，不再声称独立盲测。原标签、响应和失败记录保持原样。来源登记不足、旧响应缺失及项目范围歧义仍单独隐藏，不补推阶段/日期，也不因此阻断合格链接。本地数据已更新并完成正式构建；线上发布与全量找源未执行。
