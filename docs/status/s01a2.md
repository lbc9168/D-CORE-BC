# s01a2_multi_crawler 状态

## 职责（一句话）

对多个中文信源站点做定时增量爬取（列表发现新 URL → 抓文章页 → 入本地库）、对入库文章做初筛（三段漏斗判"海外中企可再生能源项目事件"），并产出健康监控报告；v3 多源化试点，与 s01a（goalfore 爬虫）平级、在 s01b 之前。当前 10 站：Tier-1 六站（yidaiyilu/powerchina/powerchina_intl/seetao/imsilkroad/solarbe）+ Tier-2 四站（sasac/cpnn/nengyuanjie/bjx，其中 bjx 为 headless+discover_only）。

## 当前功能

- 三种发现器：`html_list`（服务端渲染列表，电建国际/见道/新华丝路/索比）、`jpaas`（大汉 JPaaS CMS，运行时从壳页自取 API 参数，电建集团）、`sitemap_daily`（按日 sitemap，一带一路网）。
- 两种渲染层（`render` 字段，与发现器正交）：`http`（curl_cffi Chrome 指纹，默认，9 站）、`headless`（Playwright 隐身渲染，过瑞数类 JS 反爬墙，仅北极星）。`discover_only` 站只登记列表 URL 不抓正文（详情页有滑块墙时用，如北极星）。
- 文章页统一提取：标题（og:title/h1/`<title>`，可按站覆盖来源并剥离站名后缀）、日期（HTML 正则 + URL 兜底）、正文（按站选择器 + 最大文本块兜底）。
- 增量与幂等：URL 为主键，已见即跳过；`--baseline` 首跑只登记水位线不抓文章（不回爬历史）。
- 礼貌与容错：curl_cffi Chrome 指纹、同站间隔 ≥3s、404 跳过 / 429 等 30s / 403 停站 / 5xx 指数退避、单站单轮 300 篇熔断、站间隔离。
- 健康报告：每次运行生成 `data/reports/health_report_{date}.md`（每站新增/错误/空列表页/距上次新增天数），有告警时退出码非 0。
- 初筛（`filter.py` + `config/filter.yaml`）：三段漏斗判"海外中企可再生能源项目事件"——① 结构清洗（跨条目正文去重保留首条 + 按来源标题噪音黑名单，如 bjx 价格行情、imsilkroad 占位页）；② 新能源关键词门（标题+正文命中词表才过）；③ LLM 三轴判定（gemini-2.5-flash-lite，10 篇/批）：location（overseas/domestic/unknown）× chinese_entity（yes/no/unknown）× is_project_event，另输出 energy_type（PV/WD/HY/GT/BM/ES/HB/OTHER_RE/NOT_RE）与 country。合成规则召回优先：仅明确国内 / 明确无中企 / 非项目事件 / 明确非可再生才淘汰，判不出一律保留。增量幂等：只筛 `article_filter` 表没有的 url，每批判完立即落库（中断可断点续跑），失败批留待下轮自动重试。
- **来源无关（扩展契约）**：初筛只读 `articles` 表的 (url, site, title, content_text)，不依赖任何站点逻辑——未来新增站点或 RSS 公众号 Markdown，只需把文章落成 `articles` 一行（site 起新名即可）就自动可筛；`filter.yaml` 里没配按站噪音规则的来源自动只走通用规则。

## 如何运行

```bash
cd s01a2_multi_crawler
uv sync --extra dev
uv run crawl                 # 全部 6 站增量
uv run crawl --site seetao   # 单站
uv run crawl --baseline      # 首跑建水位线（新环境部署时执行一次）
uv run crawl --dry-run       # 只发现不写库
uv run health-report         # 单独重生成健康报告
uv run filter                # 初筛未筛过的文章（增量幂等；需 .env 里 GEMINI_API_KEY）
uv run filter --dry-run      # 只报漏斗各段数量，不调 LLM 不写库
uv run filter --limit 100    # 只处理前 100 篇（试跑）
uv run pytest tests/ -q      # 33 个测试
```

定时：Windows 任务计划每周触发 `uv run crawl`（未来迁服务器用 cron，同一命令）。

## 输入 / 输出

- 输入:`config/sites/*.yaml`（10 份站点适配器配置，含 `tier` 字段区分批次）；`config/filter.yaml`（初筛规则：新能源关键词表 + 按来源噪音黑名单 + LLM 参数）；`.env` 的 `GEMINI_API_KEY`（初筛 LLM 用，找子项目根→仓库根）。
- 输出:`data/crawl_state.db`——`articles`（url 主键、title、publish_date、content_text、status: baseline/fetched/error）、`fetch_log`（每站每轮运行统计）、`article_filter`（url 主键、verdict: relevant/rejected、stage: structural/keyword/llm、三轴字段 location/chinese_entity/is_project_event、energy_type、country、reason、model）；`data/reports/health_report_*.md`；`data/logs/crawl_*.log` 与 `filter_*.log`（UTF-8）。discover_only 站（bjx）不抓正文，初筛对其按标题判定。
- 暂不接下游：试点期不喂 s01b（初筛 relevant 集合即未来喂 s01b 的入口，接法待定）。

## 关键依赖与约束

- 依赖：curl_cffi（Chrome TLS 指纹，电建 JPaaS API 的必要条件）、beautifulsoup4、pydantic、pyyaml；初筛另需 google-genai、python-dotenv。
- 原文正文只存本地供后续提取，不对外发布（版权约束）；goalfore 链接不作对外 source_link 的约束在下游继续有效。
- 站点改版信号：列表页 0 命中会进健康报告告警；JPaaS 参数运行时自取可容忍参数级改版。
- 已知噪音：imsilkroad 标签页偶混入非文章链接（如数据库宣传页），抓到 0 字正文，已被水位线记住不复抓。
