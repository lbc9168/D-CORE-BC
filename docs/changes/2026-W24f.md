- **`_resolve_entity_en` 失败污染缓存（`815650b`，TDD）**：原实现翻译异常时把中文回退当英文写进共享 company_name_cache，**Gemini 503 等瞬时故障会被永久固化、永不重试**。回填首跑撞 Gemini 503 风暴（67→实测 486 次）暴露，污染 97 条（已清理，备份 `company_name_cache.json.bak_prepoison_clean`）。改为**仅成功才写缓存**。
- **回填改用 deepseek**（`scripts/oneoff/output/_developer_en_backfill.py`）：Gemini 持续 503 不可用 → 回填脚本改走 deepseek `LLMClient`（重试退避，与 recheck 同），**cache-first**（命中 Gemini 源缓存 1497 条 → 与 entity_en 一致；ascii 直通；其余 1193 走 deepseek，0 失败）。UTF-8 stdout 修 GBK print 崩溃。**不写回共享缓存**（保持 cache Gemini 纯净）。
  - 结果：`project_events.project_developer_en` 回填 **4903/4903**（业主非空事件）；备份 `bri_re_database.db.bak_pre_devbackfill_20260617_232627`。
  - ⚠️ **流水线（s01b，future data）仍用 Gemini**；存量回填用 deepseek（一次性，cache-first 保证重叠公司与 entity_en 同英文）——两者轻微风格差异，仅非重叠纯业主（多为外方）走 deepseek。
