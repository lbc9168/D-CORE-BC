## 背景 / 为什么

W27h 顺带发现主库 `SUR-XX-0001`（苏里南尼克里区灌溉和排水系统设施修复项目，category=Unknown）`excluded=0`——纯灌溉/排水民用基建，明显不在录入范围（发电/新能源制造/输变电）。本 session 查证三件事：

1. **主库有无回填机制**：没有。W27g 的 `sweep_nonenergy --apply`（525 行）只清了 s01b `projects.db`；主库仅有 2026-07-02 治标的一次性事务（77 条审计 + 34 条 non_renewable 迁移 + 4 条零星手工），护栏规则此后的全部演进（WtE 修正、本次民用词）主库都吃不到。用现行护栏对主库 4414 个未排除 canonical 只读全量判定，**命中 157 个**（油田/炼油/LNG/锂矿/水泥/绿氢缺装机等）——两库口径已实质脱节。
2. **护栏能否命中「灌溉和排水」**：不能。`_NONENERGY_WORDS` 有「供水/污水」但无「灌溉/排水」；SUR 案在 projects.db 的源行（id=573）同样 excluded=0，两边一致漏网。
3. **类似民用漏网还有多少**：主库民用词粗扫命中 78 个 canonical，精筛后 29 个为真漏网（道路/公路/机场/铁路/桥梁/体育场馆/医院/学校/水渠等）。

诊断途中**另发现已 apply 的 projects.db 清扫存在一类反向误杀**：真输变电工程被「矿区/油田/油气」词命中且 `_POWER_WORDS` 缺输变电语义——TFM矿区供电（"刚果（金）近十几年输变电领域最大 EPC"）、米桑油田132千伏电网南/北线、中缅管道贵港站110千伏线路、沙特Zuluf 230千伏主变供货，共 6+ 行；另有 AGO 冶金硅+多晶硅（光伏产业链硅料）被「冶金」误杀、"数字化工厂"子串误中「化工」等。

## 改动内容（全部走 TDD，先 RED 后 GREEN）

### `guardrails/nonenergy_check.py`

- `_NONENERGY_WORDS` 新增**民用基建组**：灌溉、排水、水渠、道路、公路、机场、铁路、桥梁、体育场、体育馆、医院、学校、教学楼。**不含「水利」**（避免误杀水利枢纽水电站）。

### `tests/test_nonenergy_check.py`

- `CIVIL_INFRA_EXCLUDE`（17 例必拦）：SUR 灌溉排水、坦桑/肯尼亚灌溉、莫桑水利水渠（类别误标水电）、高速公路/道路/机场/铁路/桥梁/体育场馆/医院/学校/教学楼、给排水+化工双命中回归。
