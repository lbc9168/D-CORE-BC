## 根目录（新增数值解析单一可信源）

### `bri_parse.py`（新增）
- `parse_number(val)`：脏文本（`约50` / `50-60MW` / `1,200` / `50 兆瓦`）→ float；范围取中点；空/NA/不可解析返回 None。
- 范围识别先于通用取数，避免 `-` 在两数间被当作负号（修正了计划样例代码的 `50-60 → -5` bug）。

### `tests/test_parse_number.py`（新增，TDD）
- 覆盖纯数值、含单位/空格/千分位、约值、范围取中点、不可解析、0。
