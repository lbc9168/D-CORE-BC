2. **子类（subcategory）机制**（光伏分集中式/分布式；综合能源分光储/其他）：

3. **储能 Capacity 修复与常设化**（纯 ES 项目储能容量此前到不了前端）：

4. **光伏子项容量**（用户确认：光储项目要能分别列出光伏和储能容量）：
   - `project_events` 新列 `pv_capacity_mw REAL`，仅综合能源(HB)项目回填（纯光伏项目 capacity_mw 即光伏容量）；`storage_parser.extract_pv_capacity` 从 capacity_details 解析（MW/兆瓦、GW/吉瓦×1000、万千瓦×10、kW÷1000，能量单位负向排除），不改 prompt。储能能量同步扩展 GWh/兆瓦时/吉瓦时（副本演练 misses 实证：单位扩展后 misses 101→51）。
