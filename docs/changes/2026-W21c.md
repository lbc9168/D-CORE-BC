## 新增 `scripts/migrate_v2.py`

一次性迁移脚本。默认 dry-run（整个迁移在单事务内执行后 ROLLBACK，仅打印将发生的改动）；`--apply` 才提交，且提交前自动 `shutil.copy` 出带时间戳 `.bak`。复用 `bri_parse`、`clean_historical_data` 的 `STAGE_MAP/INVOLVEMENT_MAP`。

迁移内容（幂等）：
1. **schema 升级**：`RENAME COLUMN capacity_mw→capacity_mw_raw` 等 + `ADD COLUMN ... REAL`；project_events 加 `storage_power_mw/storage_energy_mwh/capacity_source`；canonical 加 `excluded/excluded_reason`。
2. **数值回填**：`bri_parse.parse_number` 把各 `*_raw` 解析进 REAL 列；有值容量标 `capacity_source='legacy'`；单事务 `executemany`。
3. **储能正则**：从 `capacity_details` 提取（关键词在数值前以区分发电容量）：功率 `(?:储能|bess|储电)…(\d+)mw(?!h)`、容量 `(\d+)mwh`。
4. **脏枚举清洗**：category 合法重分类（光热/新能源→综合能源、抽水蓄能/水利水渠→水电、垃圾发电→生物质）+ 垃圾值→Unknown，**非 RE 类别保留原值另行排除**；project_stage / involvement_type 复用既有 map（stage 补 `''→Unknown`）；新建 FINANCING_MAP（PPP/BOT/PPP 变体/业主自筹→其他、`''→Unknown`）。
5. **非 RE 排除**：石油/油气/煤炭/矿产/工业园区/基础设施/农业灌溉/房建等 20 类 → `excluded=1, excluded_reason='non_renewable'`，保留原 category 可追溯。
6. **断言**：四枚举列 distinct ⊆ `enums.valid_*()`（category 仅查 `excluded=0`）；行数前后不变。
