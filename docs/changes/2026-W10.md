- 新增 ISO3 数字代码、更新 BRI 成员状态、补充 LDC 标志

### improve duplicate candidate detection — 改进去重候选筛查

- `tools/duplicate_merger_tool.py` 去重候选筛查升级为四路信号 OR 逻辑：
  - Signal 1：CN 名称 `token_sort_ratio ≥ 85`
  - Signal 2：EN 名称 `token_sort_ratio ≥ 80`
  - Signal 3：CN 名称 `partial_ratio ≥ 90`（子串包含）
  - Signal 4：容量精确匹配（误差 ≤ 1%，≥ 0.5MW）— 跨语言历史数据安全网
  - 实体辅助通道：共有中方实体 + 名称中度相似（≥ 60）
