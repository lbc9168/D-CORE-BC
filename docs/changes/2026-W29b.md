## 2026-07-16 · headless 渲染层 + 北极星接入（瑞数分层反爬墙实证）

- **涉及模块**：s01a2 新增 `headless.py`（HeadlessFetcher）、config 加 `render`/`discover_only` 两字段、`main.py` 拆 `_make_fetcher`/`_run_site`（try/finally 保证浏览器关闭）、`fetcher.py` 加 no-op close 对齐接口、新增 `bjx.yaml`、playwright 入依赖。
- **背景**：用户要求实现 headless parser 并把北极星接进来跑 baseline。先做探测确认北极星是普通 SPA 还是反爬墙。
- **探测结论（重要）**：北极星用**瑞数（Riverdata）分层 JS 反爬墙**——① 纯 curl_cffi 挡在 62KB 空壳外；② 裸 headless（webdriver=true 露馅）被甩验证页；③ **隐身 headless（藏 webdriver + `--disable-blink-features=AutomationControlled`）可过列表页**，实测拿到 133 条文章 URL；④ **但文章详情页触发滑块验证码（"滑动验证页面"），隐身过不了**（直接 goto 与会话内点击均失败）。即列表轻拦、详情硬拦。
- **做了什么**：实现 headless 渲染层（与 http 层接口兼容，`render` 字段正交于 `parser`，现有 9 站零影响、延迟导入 playwright）；北极星设 `discover_only=true`（只登记列表 URL 不抓正文，避免正常运行反复撞滑块刷错误）；建立 baseline 133 URL。**修一个数据污染 bug**：墙检测原只认英文 `Verification`，漏中文变体（访问验证/滑动验证页面）导致挑战页被当正文入库（已清 2 条垃圾并加 `"验证" in title` 通用检测）。
- **影响/遗留**：s01a2 现 10 站；bjx 停在 URL-发现级（133 条），正文获取被滑块阻断→ **defer**（下一轮方案：a) 从列表页提取标题即可支撑重叠率标题比对，b) 值得的话再投入滑块求解）。18 测试通过。playwright 浏览器本体需 `playwright install chromium`（用户级缓存，跨环境共享）。**难度重估**：北极星从"中等（隐身即可）"上修为"列表易、正文难（滑块）"——是否值得攻正文，由下一轮重叠率数据定。
