# 2026-W32 变更日志

## 储能项目分类影子架构

- S2 新增受控发电源、五态储能状态、储能 MW/MWh 原文与能源构成证据契约；legacy Category 暂作对照，模型不决定影子类别。
- 新增 `energy_taxonomy_v1` 确定性策略与严格历史文本解析，排除年发电量、工厂年产能、设备出口、预留/可选配置等误判。
- 主库事件增加能源事实列；新增 `project_classification_shadow`，含聚合容量、建议类别、标签、版本、复核及人工锁定。迁移默认 dry-run，apply 前备份并验证 ID 集合。
- Pipeline 将 2B-7 调整为严格事实回填且停止新增“综合能源/光储”，新增默认启用的 2B-8 影子汇总与 CSV/JSON 报告；不改 s03/s04。
- canonical ID 永久保留；新 ID 仍按国家 ISO + 创建时类别码 + 顺序号生成。去重增加同国家跨类别强匹配救援，避免类别修正导致新建项目。
- Gold schema 增加四个可选 taxonomy 字段；新增集合、状态、数值与派生类别指标，旧 gold 兼容且综合评分权重不变。
- 新增分类矩阵、解析负例、聚合、影子写入/人工锁定、迁移幂等、跨类别去重、eval 兼容及 pipeline 集成测试。

## 延后事项

- 本轮不迁移存量正式类别、不清理已有“综合能源/光储”、不重导 s03、不改前端。
- Golden standard 完成后再制定 prompt/model 调优与正式切换方案；切换必须保持 canonical/event ID、实体外键和项目数不变。

## Golden Standard Studio 富金标准契约

- 新增独立 Studio 的 Pydantic 富金标准模型：字段五态、文章证据、项目实体角色、候选包、难度评分和数据集 manifest。
- 字段状态仅包含 `present`、`not_mentioned`、`not_applicable`、`uncertain` 与 `needs_adjudication`；`unreviewed` 仅表示复核库草稿的文章状态。
- 发布边界要求文章已复核并拒绝任何 `needs_adjudication` 字段；`uncertain` 可保留在富金标准中，供后续投影标记为评测不适用。
- 新增唯一 FIELD_REGISTRY，集中定义 19 个审阅字段的类型、证据要求和评测指标。
- 补充字段边界回归覆盖：`present` 无值、无效证据偏移及无效文章 SHA-256 均被拒绝。

## Golden Standard Studio 只读数据源

- 新增 `SourceRepository`：以 SQLite URI 只读模式和 `query_only` 连接 raw-news、extraction 与主库，读取不会修改导入标记或源库。
- 新增不可变文章与当前项目标签快照；保留原始列值并提供仅作空白清理的展示值，事件来源链接可映射至主库项目/实体，未导入记录回退 extraction 标签。
- 数据集可记录三个源数据库的 SHA-256 逻辑快照哈希；覆盖只读拒写和读前/读后源库哈希不变的回归测试。
- 修正只读源库边界：extraction 回退仅读取 `imported_to_s02a` 为 0/NULL 的待导入行；损坏的事件 `source_links` JSON 严格拒绝，不作裸 URL 回退。
- 源库哈希改为只读事务中的确定性逻辑快照（schema + 排序表行），可捕获已提交但仍位于 SQLite WAL 的内容；补充 WAL、映射不可变性和导入标记回归覆盖。
- 主库标签按 `project_events.id`、extraction 回退按行 `id` 显式升序，避免 SQLite 查询计划改变返回顺序；补充等价行反向插入仍产出相同逻辑快照哈希的回归测试。
