# 2026-W32 变更日志

## 储能项目分类影子架构

- S2 新增受控发电源、五态储能状态、储能 MW/MWh 原文与能源构成证据契约；legacy Category 暂作对照，模型不决定影子类别。
- 新增 `energy_taxonomy_v1` 确定性策略与严格历史文本解析，排除年发电量、工厂年产能、设备出口、预留/可选配置等误判。
- 主库事件增加能源事实列；新增 `project_classification_shadow`，含聚合容量、建议类别、标签、版本、复核及人工锁定。迁移默认 dry-run，apply 前备份并验证 ID 集合。
- Pipeline 将 2B-7 调整为严格事实回填且停止新增“综合能源/光储”，新增默认启用的 2B-8 影子汇总与 CSV/JSON 报告；不改 s03/s04。
- canonical ID 永久保留；新 ID 仍按国家 ISO + 创建时类别码 + 顺序号生成。去重增加同国家跨类别强匹配救援，避免类别修正导致新建项目。
- Gold schema 增加四个可选 taxonomy 字段；新增集合、状态、数值与派生类别指标，旧 gold 兼容且综合评分权重不变。
- 新增分类矩阵、解析负例、聚合、影子写入/人工锁定、迁移幂等、跨类别去重、eval 兼容及 pipeline 集成测试。
