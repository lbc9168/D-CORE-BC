## 2026-04-19（hotfix）

### s04_web_visualization — 省级地图省名匹配修复

**根本原因**：`projects_flat.json` 中省份名称由 AI 提取，使用英文（如 "West Java", "Balochistan"）；Natural Earth GeoJSON 的 `name` 字段存储本地名/缩写（如 "Jawa Barat", "K.P."）；两者归一化后无法匹配，导致大量有省级信息的项目在地图上无法着色显示。

**修复**：Natural Earth GeoJSON 自带 `name_en` 字段，其英文值与数据中的省名完全对应。

- `src/components/map/ProvinceMap.tsx`：`rawName` 提取逻辑改为优先读 `name_en`，fallback 到 `name` / `NAME`（3 处 rawName 赋值均已修改）
- `src/pages/MapPage.tsx`：省份点击过滤从 `.includes(norm.split(" ")[0])` 的模糊首词匹配改为精确归一化匹配（去除后缀 province/state 等后严格相等），避免 "West Java" 匹配到所有含 "west" 省份的误召回

## 2026-04-15（hotfix #2）

### s04_web_visualization — 点击国家后白屏修复

**根本原因（多重叠加）：**

1. **路由结构问题**：`App.tsx` 使用无路径父路由 `<Route element={<Layout />}>`，在 React Router v6 中可能导致路由匹配边缘情况。改为标准嵌套路由：`<Route path="/" element={<Layout />}>` + `<Route index element={<MapPage />}>` + 子路由使用相对路径（`table` / `reports` / `about`）
2. **高度链断裂**：`Layout.tsx` 的 `<main>` 缺少 `flex flex-col`，导致子页面的 `h-full` 依赖隐式 flex 拉伸而非明确的 `flex-1`。修复：`main` 改为 `flex-1 flex flex-col overflow-hidden`；`MapPage` / `TablePage` 根 div 从 `h-full` 改为 `flex-1`；loading/error 状态 div 同步从 `h-full` 改为 `flex-1`
3. **ProvinceMap zoom 过大**：`computeCountryFit()` 计算缩放上限为 50，对小国（如岛国）会产生 zoom=50 传给 `ZoomableGroup`（maxZoom=8），导致 d3-zoom 以极端比例渲染 SVG 坐标溢出崩溃。修复：将 zoom 上限从 50 改为 6（与 maxZoom 对齐）
4. **ProvinceMap "idle" 状态未处理**：状态 "idle"（首次挂载、useEffect 尚未执行）未被 loading 分支捕获，直接落入 "unavailable" 分支，导致地图加载前短暂显示"无省级信息"占位符。修复：loading 判断改为 `geo.status === "idle" || geo.status === "loading"`
