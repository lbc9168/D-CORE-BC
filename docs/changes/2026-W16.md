## 2026-04-14

### external-tools/external-link-adder — 自动填充项目网站链接（新增）

**背景**：`projects_by_source.xlsx`（约 6389 条全球能源项目记录）的 `official_website` 和
`non_official_website` 两列存在大量空白，需要自动搜索填充。

- 新增 `external-tools/external-link-adder/fill_links.py`
  - 搜索工具：Serper API（Google 搜索），每次搜索后 sleep 0.5s 限速
  - 判断工具：Gemini 2.5 Flash Lite，区分 official / non-official 链接类型
  - 两轮搜索策略：第1轮用 `{implementing_entity} {project_name}`，无结果时第2轮用 `{project_name} {country}`
  - 跳过条件：任意一列已有值则跳过
  - 断点续传：启动时读取已有输出文件恢复进度，每50条自动保存
  - 支持 `--dry-run`（不保存）和 `--limit N`（仅处理前N条，测试用）
  - 输出 `search_log.txt`（TSV，含 query / 链接 / reason / status）
- 新增 `external-tools/external-link-adder/requirements.txt`
- 新增 `external-tools/external-link-adder/.env`（存放 SERPER_API_KEY）
