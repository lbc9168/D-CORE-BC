### s04_web_visualization — UI 现代化 + 地图小国修复

**P1：地图 UI 修复**

- `ProvinceMap.tsx`：新增 `computeCountryFit()` 函数，在省级 GeoJSON 加载完成后遍历所有 feature 坐标点，计算包围盒（minLng/maxLng/minLat/maxLat），自动设置地图中心和缩放级别（公式 `min(360/lngSpan, 180/latSpan) * 0.65`，范围 [1, 50]）。解决点击小国后地图过小、不居中的问题
