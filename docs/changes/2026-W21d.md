## Task 1 · s02a 编号生成改数值排序（TDD）

- `duplicate_merger_tool.py` `_gen_canonical_id` / `_gen_event_id`：原 `SELECT id ... ORDER BY id DESC LIMIT 1` 是**字符串排序**，尾号超 9999 / 99 后会把 `...-9999` 误当最大 → 生成重复编号。
- 改为 `SELECT MAX(CAST(substr(id, len(prefix)+1) AS INTEGER)) ... WHERE id LIKE ?`，取真正最大数值 +1；超界时 `:04d`/`:02d` 自然变长（如 `10001`），仍数值可排。
- 新建 `tests/test_id_generation.py`（4 用例）：跨 9999/99 边界不重复 + 首个编号正确。先红（2 failed：返回 10000/100）后绿（4/4）。
- **现有 canonical_id / event_id 未发生任何变化**（编号稳定，只改"未来新编号怎么生成"）。

## Task 2 · s03 计算 display_order 写入 projects_flat
