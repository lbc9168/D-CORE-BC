## B5 · 地点归一（normalize_locations）— 含一处误并修复

### 初次真跑暴露系统性跨省级联误并
`normalize_locations` 写 `canonical_projects.location_norm`（只增列，不动 `location`，下游 s03/s04 不消费 → 全程零功能影响、可逆）。

初次真跑（910 候选）后审计发现 **union-find 跨省级联误并**：共享后缀（州/省/岛）或共享词（爪哇/苏拉威西/苏门答腊）的"桥接对"被 LLM 误判 same，传递性地把不同省并成一坨：
- 「苏拉威西省」← 17 个不同地名（混入南苏门答腊省/岛）；「西爪哇省」← 16 个（混入亚齐省、巴厘岛）；
- 「苏尔汉河州」(UZB) ← 15 个不同省（塔什干/安集延/纳曼干…）；「西加里曼丹省」← 全部东/中/南加里曼丹；「阿拉木图市」(KAZ) ← 5 个不同州。

根因：候选门槛松（partial≥85 见后缀即触发、token≥70 见共享岛名即触发）+ 短缩写桥接（「南苏」partial=100 同时嵌进南苏拉威西省/南苏门答腊省）+ 多地名串（「北马鲁古省, 西爪哇省」partial 命中单省）+ positional 对 ≤3 字过宽（广东/广西 同首字 0.5）。

### 修复 `bri_location.py`（TDD，根共享模块）
新增 4 道候选守卫（`find_location_candidates`）：
1. **多地名串排除** `_is_multiregion`：含 `、，,;；/／` 的串无单一规范名，出局。
2. **partial 长度比守卫** `LOC_PARTIAL_MAX_LEN_RATIO=2.0`：防短缩写 partial=100 嵌进长地名（南苏→南苏拉威西省、雅加达→雅加达东部…）。
3. **方向签名守卫** `_directionally_distinct`：裸核心相同但方向标记不同（东南西北中上下，可作前缀「西爪哇」/复合「中部爪哇」/后缀「爪哇岛西部」）→ 不同子地区，出局。裸核心剥离行政后缀 + 部/岛连接字。
4. **positional 最小长度** `LOC_POSITIONAL_MIN_LEN=4`：≤3 字地名同首字仅 0.5 过宽（广东/广西、江苏/江西、巴厘岛/巴淡岛）。

真合并不误杀（信德/信德省、卡宾达/卡宾达省、达瓦德密/达旺德米、塞阿拉/塞阿腊、雪兰莪/雪兰莪州、中爪哇/中爪哇省）。
候选数 910 → **423**。测试 `tests/test_bri_location.py` 10→**16 passed**（新增 6 守卫用例，全程 RED→GREEN）；回归 root 117 / s02a 48 全绿。
