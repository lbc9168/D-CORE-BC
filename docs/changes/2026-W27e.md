## 改动内容（按层）

### Layer 0：确定性非能源守卫（`guardrails/nonenergy_check.py`）

- 新增 `check_nonenergy(name, summary, category, capacity_mw, capacity_details) -> str | None`：
  - 关键词白名单覆盖：名称/摘要中有光伏/风电/水电/核电/地热/储能 → 放行。
  - 关键词黑名单：天然气、油田、LNG、采矿、化工、矿业等 → 排除，理由字符串返回。
  - 容量吨/年守卫：调用 `capacity_is_tonnage(capacity_raw, capacity_details) -> bool`，命中则返回排除理由（`capacity_mw` 置 NULL 而非 ÷1000 启发式处理）。
  - 绿氢/电解守卫（用户规则 2026-07-02）：名称或摘要含「绿氢/电解/氢氨醇」关键词，若未同时满足「明确可再生能源种类 + 明确装机容量 (>0 MW)」→ 排除。
  - **设计决策**：绿氢规则措辞用「绿电来源种类（光伏/风电/水电等）」而非「可再生能源种类」，因既有 prompt 禁止 S2 出现「可再生能源」（保护火电 recall），Task 5 提 PR 讨论后用户裁定统一口径。
- 审计 CSV 验收（3 个关键数字）：**confirmed_nonenergy 58/71 拦截**（82%，≥55 验收线通过）、**legit_energy 0/7 误杀**（0，硬性约束通过）、**borderline 5/6 拦截**（较积极，属预期范围）。
- **有意的不覆盖**：混合型 confirmed 案（名称同时含发电词，如"氧化铝厂+配套发电厂"、"PPC 水泥线暨 8MW 光伏"）确定性层不拦——由 prompt 层与人工审计兜底。

### Layer 0 接入生产写库路径（`tools/project_extractor_tool.py`）

- `_write_valid_project()`：写库前调用 `check_nonenergy()`，命中则改写 `excluded=1`、`exclude_source='deterministic_guard'`，项目仍落 `extracted_projects`（供追溯）但对 s02a 不可见。
- **同时修复预存在缺口**：`_write_chinese_unnamed_project()` 分支原先若 S2 返回 `in_scope=false` 则**静默丢弃**（无任何写库），现统一写 `excluded=1, exclude_source='extraction'`，确保所有 S2 排除决策留有记录。

### Layer 0+：容量吨/年守卫（`tools/project_extractor_tool.py`）

- `capacity_is_tonnage(capacity_raw, capacity_details)` 检测容量字段以「吨/年」「万吨」计的情形。
- 命中时：`capacity_mw` 置 NULL（不做 ÷1000 启发式转换），`capacity_mw_raw` 保留原文备查；写库后日志记录警告。

### Layer 1（S1 prompt 收紧，`prompts/s1_relevance.py`）

新增排除条件：
- 矿产/化肥/化工/冶金/建材产品本身不录入（仅设备/材料厂录入）。
- 制造业限新能源装备/材料（光伏组件、风机、储能设备等）；矿产配套电厂无中企参与→排除。
- 情形 7（新增）：绿氢须明确可再生能源发电来源种类（光伏/风电/水电），仅提「绿氢」或「电解」无能源种类 → 排除。

### Layer 2（S2 prompt 收紧，`prompts/s2_basic.py`）

- 综合能源（HB）定义收紧：每个子项目必须有「发电/储能 + MW/MWh 计量」；能源品种相加但全无 MW/MWh → 不算综合能源。
- 绿氢分类规则：按绿电来源种类分类（光伏→PV，风电→WD，水电→HY）；来源未明确→ `in_scope=false`。
- `in_scope=false` 出口：`Category` 必须写 `Unknown`（不准硬挤已有能源类别）。
- **措辞裁定**：绿氢规则用「绿电来源种类（光伏/风电/水电等）」，见 Layer 0 注。

### 回溯清扫 CLI（`tools/nonenergy_sweep.py`，`pyproject.toml: sweep_nonenergy`）

- `uv run sweep_nonenergy [--db PATH] [--out PATH]`：遍历 `extracted_projects`（excluded=0），调 `check_nonenergy()`，dry-run 默认输出 CSV 报告；`--apply` 先备份（`.bak.YYYYMMDD_HHMMSS`）再批量更新。
- `--db` 不存在时友好报错；`--apply` 在两个连接并发时用 `try/finally` 保证连接关闭。
