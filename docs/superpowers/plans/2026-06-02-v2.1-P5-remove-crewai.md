# v2.1 P5 — 去 crewAI 薄壳清理 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（或 executing-plans）逐 Task 执行。步骤用 `- [ ]`。
> 创建：2026-06-02。上游：`docs/rules_and_plans/v2.1_plan.md`（P5 行）、`docs/superpowers/plans/2026-05-31-v2.1-P1-extraction-restructure.md` 的 **Phase 5（Task 5.1）= s01b 去 crew 的范本**、变更日志 `docs/changes/2026-W22c.md`（s01b 去 crew 实录）。

**Goal:** 把 crewAI 从仓库**彻底移除**。s01b 已在 P1 去 crew；本期清理剩余三个"1 agent + 1 task"薄壳子项目 **s01a_news_crawler / s02a_duplicate_merger / s02c_cross_verification**，并修复 **pipeline/flow.py**（crewAI Flow + 已断的 s01b crew 引用）。纯机械重构，**不改任何数据逻辑/提取输出**。

**Architecture:** 每个薄壳子项目的真实工作都在确定性 Python Tool（`*_tool.py` 的 `_run`）里，crewAI 仅是"1 agent + 1 task"外壳，agent 层无推理/编排/委派/memory（已由 2 个 Explore agent 全管线排查确认，见 `docs/changes/2026-W22a.md`）。去 crew = ①Tool 去 `BaseTool` 继承改普通类 → ②删 `crew.py`/`config/agents.yaml`/`config/tasks.yaml` → ③`main.py` 去 crew kickoff/train/replay/test、`run()` 改直接调 `Tool()._run(...)` → ④`pyproject.toml` 移除 crewai 依赖/`[tool.crewai]`/`run_crew/train/replay/test` 脚本、补直接依赖 → ⑤验证（`uv sync` 卸 crewai、smoke import、`git grep crewai` 空、既有测试绿）。

**Tech Stack:** Python 3.12 + uv（各子项目独立 venv）。无新依赖（反而卸载 crewai + ~116 传递依赖）。

**性质说明（重要）：** 这是**机械重构、行为不变**，不是新功能——没有"先写失败测试"的 TDD 红灯可写。验证口径=**特征化/冒烟**：`Tool()._run` 仍可作为普通类调用、`import` 不报错、`git grep crewai` 全空、各子项目既有单测仍绿。（与 P1 Phase 5 的验证方式一致。）
