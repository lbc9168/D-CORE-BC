# v2.1 P3 · 去重分组改造 + 地点归一化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 s02a 去重的两类系统性漏合并（跨阶段同项目被 stage 分组隔开；音译地名变体让地点信号失效），并新建地点归一化能力，为 P3 之后的 canonical 全量重建提供正确的去重逻辑。

**Architecture:** 四件事——(a) 候选预分组去掉 `project_stage` 维度，跨阶段同项目合并语义改为"按阶段分摊合并 + `dedup_group_id` 锚定同一 canonical"；(b) 候选信号级联加 Signal 6 地点/容量硬锚点，跨批次 canonical 匹配加地点辅助通道；(c) 新建根级共享模块 `bri_location.py`（音译地名三信号 + LLM 确认 + Union-Find），s02a 在去重前做批内 in-memory 归一、s02b 新增 `location_normalizer.py` CLI 做落库归一（写新列 `canonical_projects.location_norm`，绝不覆盖原 `location`）；(d) 实跑落库为 GATED 人工 runbook（副本先行 + 已知 case 验证 + .bak）。

**Tech Stack:** Python + sqlite3 + rapidfuzz + google-genai（Gemini）；TDD（pytest）；LLM 调用全部 mock 进单测。

**上游文档:** 设计草稿 `docs/rules_and_plans/sessions/S5_dedup_location.md`（Task 2-5 = 本计划范围；Task 1/S5d 已在 v2.0 完成）；roadmap `docs/rules_and_plans/v2.1_plan.md` P3 行；待办 `docs/status/backlog-v2.1.md` D 节。

## 背景与设计决策（已根据 2026-06 现状更新，偏离草稿处标注 ⚠️）

1. **⚠️ 草稿"重大决策1（存量回溯 vs 仅前向）"已被主线决策化解**：用户已拍板 P3 落地后做 **s02a canonical 全量重建**（从 `extracted_projects` 11,909 行重跑，见 backlog C2 节）。重建 = 全部存量数据自然流经新去重逻辑，**无需单独的"存量回溯重去重"任务**。这也改变了 (c) 的运行时机设计（见决策 3）。
2. **跨阶段合并语义**（草稿提到但未给实现）：分组去掉 stage 后，union-find 组可能横跨多个阶段。**不能**把跨阶段记录用 `_merge_group` 折叠成一条（会丢事件）。正确语义：组内**按 `project_stage` 分摊**，每个阶段分摊内部各自合并为一条记录，所有产出记录打上共享的 `dedup_group_id`；`_write_to_db` 见到相同 `dedup_group_id` 直接复用首条创建/匹配到的 `canonical_id`（跳过名称匹配——否则低名称分的跨阶段对会在 canonical 层重新分家，前功尽弃）。落库结果 = 一条 canonical + 每阶段一条 event（现有 `(canonical_id, project_stage)` 事件键天然支持）。
3. **⚠️ 地点归一化拆成"共享逻辑 + 两个消费端"**（草稿只设计了"去重后对 canonical 落库归一"）：已知 case 达瓦德密 vs 达旺德米是**批内**两条记录——重建时 11,909 行在同一批，若归一化只在去重后落库，Signal 6 锚点在去重时拿到的还是原始串，锚不上。因此：共享逻辑放仓库根 `bri_location.py`（与 `bri_enums`/`bri_parse` 同模式，s02a 已有上溯 import 机制）；**s02a 在候选筛查前对批内 location 做 in-memory 归一**（写 `project["location_norm"]`）；**s02b `location_normalizer.py` CLI** 在去重后对 canonical 落库归一（供后续增量批次的跨批匹配用）。
4. **`location_norm` 是新列，只加不覆盖**（草稿决策 2 维持）：`canonical_projects` 加 `location_norm TEXT`；未归一的行留 NULL，所有消费方"`location_norm` 优先、回退 `location`"。schema 同步检查已做：s03 全部 `SELECT *` + `dict(r)` 按列名取值（`flat_builder.py:146` 等），加列不破坏下游；s01b 不涉及；s03 暂不消费 location_norm（YAGNI，留到 s03 重跑时评估）。迁移 = `_init_db` 的 idempotent ALTER（s02a 建库路径）+ CLI 自带 ALTER（存量库路径）。
5. **模型常量收口**（草稿决策 5）：`LLM_CONFIRM_MODEL` 从写死的 `gemini-3-flash-preview`（preview 版）改为 `os.getenv("S02A_LLM_CONFIRM_MODEL", "gemini-2.5-flash-lite")`——默认稳定版，要换更强模型用环境变量，不改代码。
6. **跨批次 canonical 地点辅助**不用"名称分加权"，改为独立通道：名称分不足 70 时，若有同规范地名的 canonical，取其中名称分最高者，先过 `_capacity_guard`（容量差 >20% 直接放弃），再送 LLM 确认。原因：音译变体名称分可能 <20，任何"加权"都救不回来；LLM prompt 本就含地点+容量上下文，规则 1/4 兜底。
7. **Signal 6 设计**：仅在 Signal 1-5 全部未命中时触发；条件 = 规范地名（norm 优先回退原文）非空、长度 ≥2 且相等 + 双方容量可解析、均 ≥10MW 且差异 ≤15%。容量约束防止"同一省份全部光伏项目两两送 LLM"。
8. **LLM 成本量级**（重建场景预估）：地点归一化按国家分组，每国不重复地名通常 <50 个，候选对几十量级 → 全库归一约 10-30 次 LLM 调用；Signal 6 新增候选与 canonical 地点辅助各为个位数~几十次确认调用。可忽略不计（对比 C2 critic 的 4 千次）。

```python
"""bri_location.py — 地名归一化共享逻辑（单一可信源）

为音译地名变体（达瓦德密 = 达旺德米）调校的三信号候选筛查 + LLM 批量确认 + Union-Find 规范名映射。
两个消费端：
  - s02a duplicate_merger：去重前对批内 location 做 in-memory 归一（写 project["location_norm"]）
  - s02b location_normalizer：对 canonical_projects.location 做落库归一（写 location_norm 列）

模块顶层不依赖 google-genai：client 以鸭子类型传入（任何带 .models.generate_content 的对象），
LLM 失败保守不合并并 logging.error 记录。
"""
import json
import logging
import time
from typing import Dict, List, Tuple

from rapidfuzz import fuzz

logger = logging.getLogger(__name__)

LOC_TOKEN_THRESHOLD    = 70    # 信号1：token_sort_ratio（地名短、音译差异大，阈值低于实体归一的 80）
LOC_PARTIAL_THRESHOLD  = 85    # 信号2：partial_ratio（覆盖「信德」vs「信德省」等行政后缀差异）
LOC_POSITIONAL_RATIO   = 0.5   # 信号3：等长逐位相同比例下限（达瓦德密 vs 达旺德米 = 0.5）
LOC_POSITIONAL_MAX_LEN = 6     # 信号3 仅用于 ≤6 字短地名（长地名交给信号1/2）
LOC_MIN_LEN            = 2     # 双方最短长度（过滤单字噪声）
LLM_BATCH_SIZE = 25
LLM_MODEL      = "gemini-2.5-flash-lite"


def _positional_variant(a: str, b: str) -> bool:
    """信号3：等长、首字相同、逐位相同比例达标的逐字音译变体检测（token/partial 对这类串均失效）。"""
    if len(a) != len(b) or not a or a[0] != b[0] or len(a) > LOC_POSITIONAL_MAX_LEN:
        return False
    same = sum(1 for x, y in zip(a, b) if x == y)
    return same / len(a) >= LOC_POSITIONAL_RATIO


def find_location_candidates(names_with_counts: List[Tuple[str, int]]) -> List[Dict]:
    """三信号扫描（同一国家内的）地名对，返回候选对列表（结构同 entity_normalizer 候选）。"""
    names = [n for n, _ in names_with_counts]
    count_map = dict(names_with_counts)
    candidates: List[Dict] = []
    for i, a in enumerate(names):
        for b in names[i + 1:]:
            if len(a) < LOC_MIN_LEN or len(b) < LOC_MIN_LEN:
                continue
            signals: List[str] = []
            score_token = fuzz.token_sort_ratio(a, b)
            score_partial = fuzz.partial_ratio(a, b)
            if score_token >= LOC_TOKEN_THRESHOLD:
                signals.append(f"token_sort={score_token:.0f}")
            if score_partial >= LOC_PARTIAL_THRESHOLD:
                signals.append(f"partial={score_partial:.0f}")
            if not signals and _positional_variant(a, b):
                signals.append("positional")
            if signals:
                candidates.append({
                    "id": len(candidates),
                    "name_a": a, "count_a": count_map[a],
                    "name_b": b, "count_b": count_map[b],
                    "signals": ", ".join(signals),
                })
    return candidates


def llm_confirm_locations(client, batch: List[Dict], country: str = "") -> List[Dict]:
    """LLM 批量判断候选地名对是否同一地点的不同写法；3 次重试后保守置 is_same=False。"""
    pairs_text = "\n".join(
        f"{p['id']}. 「{p['name_a']}」(出现{p['count_a']}次)"
        f" vs 「{p['name_b']}」(出现{p['count_b']}次)  [信号: {p['signals']}]"
        for p in batch
    )
    prompt = f"""你是地理数据清洗专家。下面是「一带一路」能源项目数据库中来自同一国家（{country or '未知'}）的候选重复地点名称对，请判断每对是否指同一个地点的不同写法。

【判断标准】
- 同一地点的典型情况：音译差异（如「达瓦德密」=「达旺德米」）、简繁体差异、行政后缀有无（如「信德」=「信德省」）、明显错别字
- 不是同一地点：同一省份内的两个不同城市/县/地区，即使名称相似也不得合并；拿不准时按"不是"处理
- 规范名选择：选更常见或更标准的写法（出现次数多者优先）

【候选对】
{pairs_text}

请以 JSON 数组返回，每个元素格式：
{{"id": <编号>, "is_same": <true|false>, "canonical_name": "<规范地名；is_same=false 时留空>"}}
只返回 JSON，不要有其他文字。"""

    for attempt in range(3):
        try:
            resp = client.models.generate_content(model=LLM_MODEL, contents=prompt)
            raw = (resp.text or "").strip()
            if raw.startswith("```"):
                raw = raw.split("```")[1]
                if raw.startswith("json"):
                    raw = raw[4:]
            results = json.loads(raw)
            result_map = {r["id"]: r for r in results}
            for p in batch:
                info = result_map.get(p["id"], {})
                p["is_same"] = bool(info.get("is_same", False))
                p["canonical_name"] = (info.get("canonical_name") or "").strip()
            return batch
        except Exception as e:  # LLM/网络/解析异常统一退避重试；耗尽后保守不合并
            logger.error("地名 LLM 确认失败 (attempt %d/3, country=%s): %s", attempt + 1, country, e)
            time.sleep(2 ** attempt)

    for p in batch:
        p["is_same"] = False
        p["canonical_name"] = ""
    return batch


def build_union_mapping(
    names_with_counts: List[Tuple[str, int]],
    confirmed_pairs: List[Dict],
) -> Dict[str, str]:
    """Union-Find 合并确认对并选规范名，返回 {别名 → 规范名}（算法同 entity_normalizer._build_mapping）。"""
    all_names = {n for n, _ in names_with_counts}

    parent: Dict[str, str] = {n: n for n in all_names}
    canon_of: Dict[str, str] = {}

    def find(x: str) -> str:
        while parent.get(x, x) != x:
            parent[x] = parent.get(parent[x], parent[x])
            x = parent[x]
        return x

    def union(a: str, b: str, canon: str) -> None:
        for name in (a, b, canon):
            if name not in parent:
                parent[name] = name
        ra, rb, rc = find(a), find(b), find(canon)
        parent[ra] = rc
        parent[rb] = rc
        canon_of[rc] = canon

    for p in confirmed_pairs:
        if p.get("is_same") and p.get("canonical_name"):
            union(p["name_a"], p["name_b"], p["canonical_name"])

    mapping: Dict[str, str] = {}
    for name in all_names:
        canon = canon_of.get(find(name), find(name))
        if canon != name:
            mapping[name] = canon
    return mapping


def build_location_mapping(
    locations_by_country: Dict[str, List[Tuple[str, int]]],
    client,
) -> Dict[str, Dict[str, str]]:
    """按国家独立归一地名（国家间互不串改）。

    输入 {国家key: [(地名, 次数)]}，输出 {国家key: {别名 → 规范名}}；
    国家key 由调用方决定（s02a 用中文国名，s02b CLI 用 country_iso）。
    """
    result: Dict[str, Dict[str, str]] = {}
    for country, names_with_counts in locations_by_country.items():
        if len(names_with_counts) < 2:
            continue
        candidates = find_location_candidates(names_with_counts)
        if not candidates:
            continue
        confirmed: List[Dict] = []
        for i in range(0, len(candidates), LLM_BATCH_SIZE):
            confirmed.extend(
                llm_confirm_locations(client, candidates[i:i + LLM_BATCH_SIZE], country)
            )
        mapping = build_union_mapping(names_with_counts, confirmed)
        if mapping:
            result[country] = mapping
    return result
```

```python
"""location_normalizer.py — 项目地点归一化（canonical_projects.location → location_norm）

复用根 bri_location（三信号 + LLM 确认 + Union-Find），按 country_iso 分组归一。
只写新列 location_norm，绝不覆盖原 location（可逆、安全）。

使用方法（在 s02b_entity_normalizer/ 目录下）：
    uv run normalize_locations             # 正式运行，写 location_norm
    uv run normalize_locations --preview   # 仅预览候选对，不调 LLM、不写库
    uv run normalize_locations --db PATH   # 指定数据库（默认 s02a 主库）
"""
import argparse
import os
import sqlite3
import sys
from pathlib import Path
from typing import Dict, List, Optional, Tuple

# Windows GBK 控制台下强制 UTF-8 输出，避免中文乱码
if sys.stdout.encoding and sys.stdout.encoding.lower() in ("gbk", "cp936", "cp950"):
    sys.stdout.reconfigure(encoding="utf-8", errors="replace")  # type: ignore[union-attr]

_S02B_ROOT = Path(__file__).resolve().parents[2]  # s02b_entity_normalizer/
_repo_root = next(p for p in Path(__file__).resolve().parents if (p / "bri_enums.py").exists())
if str(_repo_root) not in sys.path:
    sys.path.insert(0, str(_repo_root))
import bri_location

DEFAULT_DB = _S02B_ROOT.parent / "s02a_duplicate_merger" / "data" / "db" / "bri_re_database.db"


def _load_locations_by_country(db_path: str) -> Dict[str, List[Tuple[str, int]]]:
    """读 canonical_projects 非空 location，按 country_iso 分组返回 {iso: [(地名, 出现次数)]}。"""
    conn = sqlite3.connect(db_path)
    rows = conn.execute(
        "SELECT country_iso, location, COUNT(*) FROM canonical_projects "
        "WHERE location IS NOT NULL AND location != '' "
        "GROUP BY country_iso, location"
    ).fetchall()
    conn.close()
    by_country: Dict[str, List[Tuple[str, int]]] = {}
    for iso, loc, n in rows:
        by_country.setdefault(iso or "UNK", []).append((loc, n))
    return by_country


def _write_location_norm(db_path: str, mapping_by_country: Dict[str, Dict[str, str]]) -> int:
    """把 {iso: {别名→规范名}} 写入 canonical_projects.location_norm（事务 + executemany）。"""
    conn = sqlite3.connect(db_path)
    try:
        conn.execute("ALTER TABLE canonical_projects ADD COLUMN location_norm TEXT")
    except sqlite3.OperationalError:
        pass  # 列已存在（已知无害边界，按 CLAUDE.md 规则1 沉默）
    params = [
        (canon, iso, alias)
        for iso, mapping in mapping_by_country.items()
        for alias, canon in mapping.items()
    ]
    n = 0
    if params:
        cur = conn.executemany(
            "UPDATE canonical_projects SET location_norm = ? "
            "WHERE country_iso = ? AND location = ?",
            params,
        )
        n = cur.rowcount
    conn.commit()
    conn.close()
    return n


def run(db_path: Optional[str] = None, preview: bool = False) -> None:
    """CLI 入口：加载地名 → 候选预览（preview 止步于此）→ LLM 确认 → 写 location_norm。"""
    if db_path is None and preview is False:
        parser = argparse.ArgumentParser(description="项目地点归一化（音译变体合并，写 location_norm）")
        parser.add_argument("--preview", action="store_true", help="仅预览候选对，不调 LLM、不写库")
        parser.add_argument("--db", type=str, default=None, help=f"数据库路径（默认：{DEFAULT_DB}）")
        args, _ = parser.parse_known_args()
        preview, db_path = args.preview, args.db

    if db_path is None:
        db_path = str(DEFAULT_DB)
    if not os.path.exists(db_path):
        raise FileNotFoundError(f"数据库不存在: {db_path}")

    print(f"\n{'=' * 50}\n  地点归一化工具{'（预览模式）' if preview else ''}\n{'=' * 50}")
    print(f"  数据库: {db_path}")

    by_country = _load_locations_by_country(db_path)
    print(f"  加载 {sum(len(v) for v in by_country.values())} 个 (国家, 地名) 组合，覆盖 {len(by_country)} 国")

    n_cand = 0
    for iso, names in sorted(by_country.items()):
        for p in bri_location.find_location_candidates(names):
            n_cand += 1
            print(f"    [{iso}] 「{p['name_a']}」({p['count_a']}) <-> "
                  f"「{p['name_b']}」({p['count_b']})  [{p['signals']}]")
    print(f"  候选地名对合计: {n_cand}")
    if preview:
        print("\n[预览模式] 跳过 LLM 确认与写库。")
        return
    if n_cand == 0:
        print("  无候选对，无需归一化。")
        return

    # 延迟导入：preview 模式与单测不需要 genai/dotenv
    from dotenv import load_dotenv
    from google import genai
    load_dotenv(_S02B_ROOT / ".env")
    load_dotenv()
    api_key = os.environ.get("GEMINI_API_KEY", "")
    if not api_key:
        raise RuntimeError("未找到 GEMINI_API_KEY，请在 .env 文件中配置")

    mapping_by_country = bri_location.build_location_mapping(by_country, genai.Client(api_key=api_key))
    for iso, mapping in sorted(mapping_by_country.items()):
        for alias, canon in sorted(mapping.items()):
            print(f"    [{iso}] {alias}  →  {canon}")
    if not mapping_by_country:
        print("  LLM 未确认任何同地点对，无需写库。")
        return

    n_rows = _write_location_norm(db_path, mapping_by_country)
    n_alias = sum(len(m) for m in mapping_by_country.values())
    print(f"\n  ✓ location_norm 更新 {n_rows} 行（{n_alias} 条别名映射）")


if __name__ == "__main__":
    run()
```

def _apply_location_norm(projects: List[Dict], client) -> int:
    """批内地点归一化（in-memory）：按国家分组调 bri_location，写 project["location_norm"]。

    让 Signal 6 锚点能命中音译变体；失败仅记日志，锚点回退原 location，不阻塞主流程。
    返回应用条数。
    """
    if client is None:
        return 0
    by_country: Dict[str, Dict[str, int]] = defaultdict(lambda: defaultdict(int))
    for p in projects:
        loc = _clean(p.get("location", ""))
        if loc:
            by_country[p["country"]][loc] += 1
    grouped = {c: list(d.items()) for c, d in by_country.items() if len(d) >= 2}
    if not grouped:
        return 0
    try:
        mapping = bri_location.build_location_mapping(grouped, client)
    except Exception as e:
        logging.error("批内地点归一化失败，Signal 6 锚点将回退原 location: %s", e)
        return 0
    applied = 0
    for p in projects:
        norm = mapping.get(p["country"], {}).get(_clean(p.get("location", "")))
        if norm:
            p["location_norm"] = norm
            applied += 1
    return applied
```

- **最高风险仍是误并**（不可逆丢项目）——全部新信号只把对送 LLM 确认，无任何"免确认直并"路径；Signal 6 有容量 15% + ≥10MW 双门槛；canonical 地点辅助有 `_capacity_guard` 前置；LLM prompt 拿不准按"不是"处理。最终防线是 runbook ⑥ 的人工抽查。
